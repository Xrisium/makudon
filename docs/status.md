# 当前状态

更新日期：2026-10-25。阶段：**首个原生工作区开发版；完整 MVP / 真机验收未完成**。

## 已实现

- Kotlin + Compose 单模块；复用原 SDK / JDK 17 / AGP / Gradle，无额外工具安装、网络或广泛存储权限。
- “目录 / 最近 / 设置”，默认最近；最近右上角新建按钮、柔和文稿卡片、隐藏扩展名。新建二级页含纯文本 / Markdown / 导入，明确显示目标目录，最近默认收件箱、失效时显式回退根目录。
- 简单目录树、名称搜索、五类排序 / 升降序 / 文件夹优先、展开差分、创建目录；搜索下方纯文字提示，无新建卡片和行末省略号。
- 文件与文件夹长按菜单：信息、重命名、复制 / 剪切 / 粘贴、删除；文件夹另有新建动作。名称冲突不覆盖，复制使用独立 ID 与正文，剪切成功粘贴前不删除源；删除确认显示名称、位置和递归范围。
- 私有标准 UTF-8 正文、独立目录 ID、原子元数据索引；500ms 停顿 / 最长 2s 保存调度、单写者版本校验、离开前最新输入屏障、后台尽力保存、失败重试与内存导出出口。
- 上一保存版本查看 / 显式恢复，恢复前保留现场。目录操作失败不静默覆盖，索引结果不确定时停止后续发布，重试重新读取；删除后清理失败明确提示。
- 源码与原生标题 / 段落排版均可编辑；按范围修改同一源码，保留未编辑分隔符与未知结构；跨视图共享有界撤销差量。复杂 Markdown 片段保留原样并切回源码编辑，不是完整富文本引擎。
- 本机系统选择器导入独立副本、窄范围 `content://` VIEW 候选、最小 `.txt` 导出。严格 UTF-8、BOM / 换行处理、10 万码点 / 1 MiB 限额、重复导入独立副本；活动文稿保存失败不切换。外部请求按任务 ID 去重，并保留最后一个已处理任务 ID，防止任务恢复重新导入已删除稿。
- 跟随系统 + 五个主题；完整本地 Noto Sans SC（UI 500 / 正文 450），两个字体角色分开，切换设置仅预留。Fredoka 路径组合、39 个按需 Lucide 图标与 Fluent Markdown 标识已集成；设置可离线阅读随 APK 打包的许可。

实际文件布局与边界见 [ADR 0003](adr/0003-workspace-catalog.md)，任务见 [原生工作区](tasks/0008-android-workspace.md)。原始视觉方案和例图历史保留于任务 0003–0007；不再代表当前应用只有占位页。

## 当前验证

- `Check`（构建、23 项 JVM 业务测试、严格 Lint）通过。测试覆盖保存合并与旧回执、错误重试、Unicode、原子写失败、目录冲突 / 环 / 复制 / 删除、恢复保护与外部请求去重；不再是 `NO-SOURCE`。
- 用户明确指定本轮使用模拟器；仅操作 Android_API_36 / API 36 模拟器，未操作真机，未卸载应用或清数据。恢复了模拟器历史 480px 覆盖尺寸，以物理 1080×2400 / 420dpi 进行正常手机宽度测试。
- 完整模拟器流程通过 29 项检查：真实长按、重命名 / 删除确认、复制移动、原生输入保存、双视图保真、跨视图撤销、独立 URI 导入、导出快照、非法编码、10 万码点与超限拒绝，以及 VIEW 候选、热导入和 Activity 重建去重。另通过 10 项外部审查，覆盖 force-stop 前后完整字节哈希、默认最近、搜索、排序、200% 字体和 320dp；截图已人工查看。最终证据与 APK 身份见 [验收记录](testing/2026-10-25-workspace.md)。
- 单段 10 万中文码点的一次输入 + 保存约 0.8–1.1s；含 emoji 的多段 10 万码点正文完整落盘。高比例 emoji 超长单段曾超过测试的 12s 等待，需专项优化，不宣称已达到全部输入 / 打开 / 保存 p95 目标。
- APK 为 Makudon Dev / `io.github.xrisium.makudon.debug` / `0.0.1-dev`；完整字体原始约 16.95 MiB、APK 压缩约 10.75 MiB，整个 debug APK 约 20.9 MiB。当前 APK 身份以验收记录及 `.local/last-run.json` 为准。

## 限制与下一步

- 真机中文 IME composition、字体缩放 / TalkBack 完整矩阵、长文性能 p95、所有磁盘故障与真实提交中断阶段尚未完成验收。模拟器与程序赋值不能代替用户真机输入体验。
- 完整 Markdown 富文本、跨段连续选择、图片、字体文件切换、独立备份 / ZIP、同步、回收站 / 撤销删除和正式签名发布未实现。
- `previous.txt` 与私有恢复材料不是独立备份；卸载 / 清数据仍会丢失文稿。未提供索引损坏的自动重建、孤立文件和恢复材料维护工具，不自动清除疑似数据。
- `Run` / 双击 / Ctrl+Shift+B 的默认设备分流仍未改动；后续恢复长期真机优先策略，先重新识别设备并显式传 Serial，不能沿用本次模拟器特例。
- 用户可先在已安装的模拟器开发版亲自检查编辑、主题、目录和新建流程；下一轮按明确任务继续真机体验与故障恢复验收，不自动推进路线图或推送远程。
