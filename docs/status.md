## 已实现

- 应用选择面板的系统入口显示为“安卓原生文件选择器”，采用与其他应用一致的图标文字行；图标使用 Google 官方 Android robot，来源及 CC BY 3.0 署名见[素材记录](third-party-assets.md)和应用内许可。

- 文稿导入 / ZIP 选择先选择实际处理应用，已发现的华为文件管理置前，宽类型启动后严格校验内容；元数据缺失不直接判失败。导出弹窗只显示一处状态正文，移除单独的云空间分享入口；其他应用分享仍不表示保存成功。TXT / ZIP 共用固定正文 / 名称副本、只读 FileProvider 分享、API 29+ 下载目录和系统保存位置；分享材料独立保留至少 24 小时，ZIP 源暂存清理不影响接收。厂商本地保存未验证前显示“分享”，见 [ADR 0007](adr/0007-file-manager-first.md)。

- Kotlin + Compose 单模块；复用原 SDK / JDK 17 / AGP / Gradle，无额外工具安装、网络或广泛存储权限。
- “目录 / 最近 / 设置”，默认最近；最近右上角新建按钮、柔和文稿卡片、隐藏扩展名。新建二级页含纯文本 / Markdown / 导入，明确显示目标目录；最近新建与系统导入默认根目录，不再自动创建收件箱，旧收件箱作为普通目录原样保留，见 [ADR 0004](adr/0004-root-default-without-inbox.md)。
- 编辑页标题点击重命名，复用现有对话框与保存屏障，保留编辑会话；最近卡片短按打开、长按仅显示更多信息 / 重命名 / 删除，提供长按无障碍动作，删除仍独立确认。
- 最近以手机系统时区按自然日分组：今天、3天内（昨天 / 前天）、7天内（3–6 天前）、更早以前，空组隐藏。卡片仍显示修改时间，相对日期优先，同年不带年份；跨午夜 / 时间 / 时区变化及回到前台刷新。编辑三点菜单增加详细信息 / 重命名 / 删除；信息先保存并刷新元数据，保存失败阻止删除，成功删除活动稿后释放会话并返回来源列表。
- 简单目录树、名称搜索、五类排序 / 升降序 / 文件夹优先、展开差分、创建目录；文件夹整行点击同时选中并切换展开，箭头独立切换展开。搜索下方纯文字提示，操作通知位于提示下方且样式不变，无新建卡片和行末省略号。
- 文件与文件夹长按菜单：信息、重命名、复选、复制 / 剪切 / 粘贴、删除；文件夹另有新建动作。行尾勾选支持父子去重、继承与半选，清空不退出、X 退出保留剪贴板；模式内屏蔽主标签滑动和导航。单项 / 批量共用私有剪贴板，复制快照独立，剪切成功前保留源；归并唯一目标或跨目录显式择一，整批校验后一次发布索引，删除确认名称 / 位置 / 递归范围，见 [ADR 0005](adr/0005-batch-directory-and-private-clipboard.md)。
- 私有标准 UTF-8 正文、独立目录 ID、原子元数据索引；500ms 停顿 / 最长 2s 保存调度、单写者版本校验、离开前最新输入屏障、后台尽力保存、失败重试与内存导出出口。
- 纯目录 ZIP 整库备份与三种恢复，无清单 / 设置 / 上一版本；先校验正文、CRC、路径与容量，再预览。增量逐项选择保留本地 / 采用备份 / 保留双方，路径改变视为新增；副本 ID 独立，不按时间自动覆盖。本地库首次载入建立兼容旧库的指针，恢复准备独立代际后一次切换；旧编辑保存校验库实例 / 代际。最近一次完整本地恢复快照可交换撤回、保留现场或清理，见 [ADR 0006](adr/0006-plain-zip-and-library-generations.md)。
- 上一保存版本查看 / 显式恢复，恢复前保留现场。目录操作失败不静默覆盖，索引结果不确定时停止后续发布，重试重新读取；删除后清理失败明确提示。
- 源码与原生标题 / 段落排版均可编辑；按范围修改同一源码，保留未编辑分隔符与未知结构；跨视图共享有界撤销差量。复杂 Markdown 片段保留原样并切回源码编辑，不是完整富文本引擎。
- 本机系统选择器导入独立副本、窄范围 `content://` VIEW 候选、最小 `.txt` 导出。严格 UTF-8、BOM / 换行处理、10 万码点 / 1 MiB 限额、重复导入独立副本；活动文稿保存失败不切换。外部请求按任务 ID 去重，并保留最后一个已处理任务 ID，防止任务恢复重新导入已删除稿。
- 跟随系统 + 五个主题；完整本地 Noto Sans SC（UI 500 / 正文 450），两个字体角色分开，切换设置仅预留。Fredoka 路径组合、39 个按需 Lucide 图标与 Fluent Markdown 标识已集成；设置可离线阅读随 APK 打包的许可。

## 限制与下一步

- 当前优先验证新版导出弹窗及补完华为文件交互验收：在用户处理手机系统安装阶段后复用本次安装，验证 TXT / MD / ZIP 选择与取消、文件管理接收是否支持本地保存、下载同名独立内容；不自动重复安装。其他品牌、API 26–28 实机及真实进程死亡完整流程尚未验，不以能力声明或模拟器结果代替。

- 真机中文 IME composition、字体缩放 / TalkBack 完整矩阵、长文性能 p95、所有磁盘故障与真实提交中断阶段尚未完成验收。模拟器与程序赋值不能代替用户真机输入体验。
- 完整 Markdown 富文本、跨段连续选择、图片、字体文件切换、同步、回收站 / 撤销删除和正式签名发布未实现。ZIP 只备份当前正文及目录；恢复按路径匹配，不能识别改名后的同一文稿，不自动合并正文。真实强杀阶段、厂商 provider 与大库性能未完成完整验收。
- 私有剪贴板只保留在进程内，复制快照累计 UTF-8 正文上限 8 MiB，超限需分批且保留旧剪贴板；不保证进程死亡后仍能粘贴。批量清理失败明确提示，不把残留材料当回收站。
- `previous.txt`、私有恢复材料与本地整库快照不是独立备份；卸载 / 清数据仍会丢失它们，外部 ZIP 才是独立备份。未提供索引损坏自动重建及一般孤立材料维护工具；准备阶段强杀可能留下未引用代际，不自动重放或扫描重建。
- `Run`、调试菜单的模拟器操作及 Ctrl+Shift+B 选择配置 AVD；最终真机交付可用菜单或 `InstallDevice -Serial` 对重新识别的在线真机单向覆盖安装已有 APK，不启动应用或检查进程。仅在用户要求或确有必要时进行真机调试，规则与命令见[设备约定](device-policy.md)；ZIP 版本交付与人工步骤见当前验收记录。
- 真机人工验收优先体验设置中的 ZIP 导出、电脑创建 ZIP 的三种恢复、冲突逐项选择、覆盖确认与撤回。既有主题 / 导航持续体验、真机中文输入、逐帧性能及完整无障碍仍待用户验收，不以模拟器自动化代替。不自动推进路线图或推送远程。
