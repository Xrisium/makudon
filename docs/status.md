## 已实现

- Kotlin + Compose 单模块；复用原 SDK / JDK 17 / AGP / Gradle，无额外工具安装、网络或广泛存储权限。
- “目录 / 最近 / 设置”，默认最近；最近右上角新建按钮、柔和文稿卡片、隐藏扩展名。新建二级页含纯文本 / Markdown / 导入，明确显示目标目录，最近默认收件箱、失效时显式回退根目录。
- 简单目录树、名称搜索、五类排序 / 升降序 / 文件夹优先、展开差分、创建目录；搜索下方纯文字提示，无新建卡片和行末省略号。
- 文件与文件夹长按菜单：信息、重命名、复制 / 剪切 / 粘贴、删除；文件夹另有新建动作。名称冲突不覆盖，复制使用独立 ID 与正文，剪切成功粘贴前不删除源；删除确认显示名称、位置和递归范围。
- 私有标准 UTF-8 正文、独立目录 ID、原子元数据索引；500ms 停顿 / 最长 2s 保存调度、单写者版本校验、离开前最新输入屏障、后台尽力保存、失败重试与内存导出出口。
- 上一保存版本查看 / 显式恢复，恢复前保留现场。目录操作失败不静默覆盖，索引结果不确定时停止后续发布，重试重新读取；删除后清理失败明确提示。
- 源码与原生标题 / 段落排版均可编辑；按范围修改同一源码，保留未编辑分隔符与未知结构；跨视图共享有界撤销差量。复杂 Markdown 片段保留原样并切回源码编辑，不是完整富文本引擎。
- 本机系统选择器导入独立副本、窄范围 `content://` VIEW 候选、最小 `.txt` 导出。严格 UTF-8、BOM / 换行处理、10 万码点 / 1 MiB 限额、重复导入独立副本；活动文稿保存失败不切换。外部请求按任务 ID 去重，并保留最后一个已处理任务 ID，防止任务恢复重新导入已删除稿。
- 跟随系统 + 五个主题；完整本地 Noto Sans SC（UI 500 / 正文 450），两个字体角色分开，切换设置仅预留。Fredoka 路径组合、39 个按需 Lucide 图标与 Fluent Markdown 标识已集成；设置可离线阅读随 APK 打包的许可。
- 工作区动效：三标签离散横滑 / 点击切换，底栏单个强调背景随页面进度横移、文字与图标平滑变色（跨标签跳过中间页面）；重复配色选择不写盘，设置持久化与滑动 / 过渡不再触发设置控件置灰。主题颜色渐变，打开 / 新建 / 二级页及返回的成对过渡，目录旋转箭头、条目让位、搜索展开和视图选中背景。文稿退出先保存，原会话保留至退场完成；旧回调、重建、后台和系统零动画倍率均有收尾保护。
