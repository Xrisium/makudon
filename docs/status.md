- 真机中文 IME composition、字体缩放 / TalkBack 完整矩阵、长文性能 p95、所有磁盘故障与真实提交中断阶段尚未完成验收。模拟器与程序赋值不能代替用户真机输入体验。
- 更完整的 Markdown 富文本、图片、用户自选字体文件、同步和正式签名发布未实现；跨段连续选择已随三视图接入。回收站已接入，旧版已删除内容不能自动找回，未提供删除后的即时撤销按钮。ZIP 只备份当前正文及目录，不包含回收站；恢复按路径匹配，不能识别改名后的同一文稿，不自动合并正文。真实提交强杀阶段、厂商 provider 与大库性能未完成完整验收。
