- “目录 / 最近 / 设置”，默认最近；最近右上角新建按钮、柔和文稿卡片、隐藏扩展名。新建二级页含纯文本 / Markdown / 导入，明确显示目标目录；最近新建与系统导入默认根目录，不再自动创建收件箱，旧收件箱作为普通目录原样保留，见 [ADR 0004](adr/0004-root-default-without-inbox.md)。

## 限制与下一步

- 真机中文 IME composition、字体缩放 / TalkBack 完整矩阵、长文性能 p95、所有磁盘故障与真实提交中断阶段尚未完成验收。模拟器与程序赋值不能代替用户真机输入体验。
- 完整 Markdown 富文本、跨段连续选择、图片、字体文件切换、独立备份 / ZIP、同步、回收站 / 撤销删除和正式签名发布未实现。
- 私有剪贴板只保留在进程内，复制快照累计 UTF-8 正文上限 8 MiB，超限需分批且保留旧剪贴板；不保证进程死亡后仍能粘贴。批量清理失败明确提示，不把残留材料当回收站。
- `previous.txt` 与私有恢复材料不是独立备份；卸载 / 清数据仍会丢失文稿。未提供索引损坏的自动重建、孤立文件和恢复材料维护工具，不自动清除疑似数据。
- `Run` / 双击 / Ctrl+Shift+B 的默认设备分流仍未改动；后续继续长期真机优先策略，先重新识别设备并显式传 Serial，不能固定沿用当前模拟器。
- 真机交付后由用户亲自检查重复配色 / 相近配色无闪烁、底栏强调背景横移、离散横滑、跨标签点击与编辑返回；真机逐帧性能、中文输入、持续体验及完整无障碍仍待本人验收，不以模拟器自动化代替。不自动推进路线图或推送远程。
