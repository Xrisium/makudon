## 功能与安全边界

源码与排版共用唯一正文、连续选区、共享有界撤销；排版按源码范围提供常用格式和结构输入，阅读无可编辑正文。查找替换为字面匹配；Markdown 默认导出 md，保留 txt 原文副本。格式与异步解析不全篇序列化 Markdown，不改目录存储协议。

CommonMark Java 0.24.0 核心、表格、删除线、任务列表四个 JAR 共 261,235 字节；许可来自实际 JAR 并离线展示。新增依赖不包含 WebView 或网络资源加载。最终 APK 仅含既有动态接收器签名权限，无网络和广泛存储权限。

## 真机人工验收

1. 新建 Markdown，输入中文、emoji、标题与多个段落，反复切换三模式，确认源码未因查看而变化。
2. 排版中长按选字并拖动手柄跨段，使用加粗、调整标题、续写 / 退出列表、勾选任务与撤销，确认一次操作一次撤销且邻文不变。自动化跨段选区采用原生无障碍选区动作，实际触摸手柄与 TalkBack 手势仍需人工体验。
3. 用搜狗等实际输入法在组词过程中使用工具或切换阅读，检查候选上屏、光标、删除和继续输入；模拟器 InputConnection 不能代替该体验。
4. 阅读时点击正文与任务不唤起编辑；选择复制、查找、点击空白切换沉浸、返回显示控件均可用。
5. 检查正文大小、字体、深浅主题；导出 md 与 txt，在文件管理器查看名称与原文，确认两个副本均不剥离 Markdown 标记。

图片、HTML 渲染、公式、表格单元格编辑器、完整 Markdown 富文本边界、旧系统及完整无障碍 / 性能 p95 矩阵不在本轮已验证结论中。
