## 使用与限制

- 文稿导入和 ZIP 选择每次由用户选应用；系统选择器是显式后备，不因取消自动打开。
- 导出时固定内容、名称和类型。外部保存取消 / 失败可用当前面板重试；关闭面板结束任务，下次可以生成新副本。
- FileProvider 只开放私有分享目录，只读授权；材料至少保留 24 小时，分享重试刷新保留期，下一次准备时清理过期非活动副本。它不是独立备份。
- API 26–28 没有 Downloads 快捷保存；仍可分享或系统选择位置，不新增存储权限。
- 外部 SEND 导入、其他厂商真机、API 26–28 实机、长期实际 24 小时接收行为及进程被系统真正杀死后的完整端到端流程未验。生命周期已覆盖 Activity 重建及缺失 / 迟到请求拒绝。
