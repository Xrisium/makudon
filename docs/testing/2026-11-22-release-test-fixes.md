## 存储故障崩溃

重载期间 `LibraryController.load()` 有意撤销旧句柄，主线程视口回调曾同时读取 `library.store`，抛出 `Failure.Corrupt`。位置写入也可能在无活动库时读取该句柄。编辑会话现在持有打开时的句柄；记录视口不直接读取暂时失效的控制器，落盘在 IO 锁内确认回收站可用且句柄仍为当前库，避免向已退役代际写入。正文保存屏障和失败提示未放宽。

API 36 模拟器回收站 29 项通过，包含人为撤销活动句柄后记录视口、保留缓冲、故障后重试；最近 37 项通过，包含保存失败阻止删除、重试和防复活。此前崩溃未再出现。测试仅模拟错误，不能覆盖所有磁盘故障。
