# 0.2.0 发布前模拟器测试

结论：**暂不建议发布**。测试对象是 `c64c09d` 的产品代码，版本仍为 0.1.0 / versionCode 2，不是签名后的 0.2.0 发布包。模拟器 Android_API_36（API 36，x86_64）；不代表真机或旧版 Android。本轮未修改产品代码、未发布、未操作真机。

## 初步发现

1. **发布阻塞：存储故障恢复时崩溃。** `trash` 测试在编辑已有稿、注入回收站日志写入失败并尝试恢复时进程崩溃；`recent` 的保存失败保护场景再次出现相同堆栈。崩溃为 `WorkspaceException: Corrupt`，由 `LibraryController.store` 经 `WorkspaceViewModel.recordViewport` 在主线程抛出；回收站场景中测试此前已验证内存编辑缓冲仍在，进程退出可能丢失尚未保存内容。需修复并验证恢复和正文保真后再判断发布。日志只含堆栈与合成测试数据。
2. **图片专项未完成。** 首轮在更多信息预览尺寸断言失败；复测越过该处，83 个功能断言全部通过，但清理合成数据后的工作区重载超过测试超时，最终仍失败。需调查预览节点定位 / 时序，以及批量清理或重载延迟；不能将两者直接认定为产品缺陷。
3. **视觉专项待排查。** 字号从小切到大时，两次均未采到高亮经过中间位置，均在 7 项后停止；配色专项两次在设置页找不到可点击的“纸白”，0 项完成。需区分动画帧采样、设置页滚动 / 测试入口和实际界面问题；后续测试没有覆盖。英文 320dp、200% 字号的图片信息截图已查看：预览和关闭按钮在屏幕内，信息内容超出当前可视区域；未凭单张图判断滚动可用性。
4. **极端长文性能：** 10 万码点密集 Markdown 排版滚动四段主线程回调间隔中位数 53.5–63.0 ms、p95 72.0–80.4 ms；这是模拟器回调间隔，不是 GPU 耗时或帧率。正文、选区、修订、手势及接续相关 9 项通过。对极端长文仍有明显流畅度改进空间，需真机体验和正式性能测量决定优先级。
5. **大纲测试存在不稳定性。** 首轮阅读跳到重名标题、切回源码后当前章节断言失败；复测 10 项全部通过。诊断时选区和正文仍在。应排查异步布局和断言时序，避免掩盖真实位置问题。
