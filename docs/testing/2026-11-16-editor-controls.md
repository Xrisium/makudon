# 编辑导航边距与目录长文件名（2026-11-16）

## 范围与确认边界

本轮实现用户第 1–4 项：导航控件边距、可见中轴对齐、设置更名、目录文件名单行省略及扩展名保留。第 5 项仅制作交互预览；应用内分隔线、正文羽化和开关尚未更改，等待用户确认效果后再实施。

## 实现

- 全局 NavigationInset：标准（默认）和加宽。加宽时正文容器两侧各增加 16dp 安全距离，导航控件随同内缩；正文也避开曲面区域，防止控件压字。沿用索引可选偏好、IO 互斥和失败处理，旧 / 未知值回到标准，无正文或 ZIP 格式变化。
- 滚动条中心由原距容器边缘 9dp 调到 12dp，与回顶 / 回底图标中心一致；保持 48dp 触摸区域。左右两侧一致。
- 设置分类改为“文稿编辑”，字段为“导航控件位置 / 导航控件边距”。两组独立单选语义，同一卡片以内缩分隔线区分；中英同步。
- 目录名称与扩展名分开测量，名称最多一行、右端省略，扩展名完整保留。使用 … 并仅在截断时加 2dp 间隙区分扩展名的点；实际名称、路径、文件类型和正文不变。无障碍与长按菜单保留全名，短名称紧接扩展名。窄屏深层目录收紧缩进，给类型扩展名留出空间。
