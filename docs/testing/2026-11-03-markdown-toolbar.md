## 人工体验

1. 点击三页签边缘与中心，检查选中反馈，比较三视图左下信息的垂直位置。
2. 点击文本 / 段落 / 插入：当前组收起、其他组切换；开启键盘后横滑工具栏，确认只在松手切换，正文光标保持。
3. 打开标题 / 列表菜单，检查图标、H6、键盘上的间距与短屏滚动；中文组词、跨段选区手柄、TalkBack 完整矩阵仍由人工体验，不把布局截图视为输入法全量验收。
