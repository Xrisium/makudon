# Markdown 呈现统一与长文切换验收

任务 0050 于 2026-11-26 开始，2026-11-27 继续并完成本轮模拟器验收；开发调试仅使用 API 36 模拟器。LIO-AN00 仅在最终集中推送一次应用 APK，不进行真机开发调试；另一台 Harmony 安卓兼容层测试机仍由用户人工验收。

## 差异审查与结果

旧版排版使用连续 BasicTextField 的源码投影，阅读使用 SelectionContainer + LazyColumn + 独立 ReadingNode。共享解析器与一部分行内样式并不保证最终布局相同。

| 格式 / 行为 | 旧版差异 | 本轮统一方式 |
| --- | --- | --- |
| 段落及软换行 | 排版保留源文 LF / 空行；阅读根块另加 18dp，每个块独立布局 | 同一显示投影和连续行布局；不额外加根块间距 |
| H1–H6 / Setext / ATX 尾标记 | 阅读使用 AST 标题文字；排版残留 Setext 下划线和 ATX 尾标记 | 相同字号倍率 / 字重，非活动状态隐藏结构标记；可见标题保留无障碍 heading |
| 无序 / 嵌套列表 | 阅读固定至少 24dp 标记列；排版按实际字宽悬挂缩进 | 共用按当前字体测量的前缀宽度，续行、子项及同级基线一致 |
| 有序列表 | 阅读按起始号递增；排版原样显示各行数字，且未纳入悬挂宽度 | 共用解析后的顺序编号与悬挂缩进，活动编辑仍显示原标记 |
| 任务列表 | 阅读固定 32dp 标记列；排版字形与 48dp 点击覆盖层 | 共用任务字形、间距、语义；仅排版可修改 |
| 引用 / 引用内列表 | 阅读 3dp 装饰线、12dp 内边距；排版竖线字形且列表前缀处理不同 | 共用竖线及列表前缀投影与缩进 |
| 代码 | 阅读块有 12dp 内边距及局部横滚；排版连续文字、原始代码空白 | 共用等宽与背景、随正文换行；行内代码使用解析后的空白 |
| 链接 / 引用链接 / 自动链接 | 阅读由 AST 去除全部语法；排版只处理行内 `](...)` | 共用源码范围折叠与链接样式；阅读明确点按交给原有 UriHandler |
| 转义 / 实体 | 阅读显示解析文字；排版残留反斜线 / 实体源码 | token 级解码，保留词间精确选区，不整体替换普通段落 |
| 分隔线 | 阅读 HorizontalDivider + 上下 12dp；排版文本横线 | 共用同一个显示表示及行高 |
| 表格 | 阅读另建 Text 单元格、固有高度；排版原生输入镜像、最小 48dp 行高 | 同一测量、边框、列宽、最小行高及按视口组合的行；阅读只读 |
| 图片 | 两个组件树的段落处理、可用宽度及布局规则不同 | 同一独立图片段落投影、尺寸和覆盖层 |
| 页尾 / 导航 | 阅读额外 96dp 留白、估算块高与独立锚点 | 共用完整行高、实际连续滚动范围及源码锚点 |

必要差别保留：排版活动光标 / 选区 / 组合显露相关源码，阅读不显露；排版可输入及勾选，阅读仅选择、复制、查找及明确外链动作。HTML 和不支持图片仍按原文保留，不增加 HTML / 网络渲染。

## 优化及测量

参照官方 [Lazy 列表](https://developer.android.com/develop/ui/compose/lists)和 [TextMeasurer](https://developer.android.com/reference/kotlin/androidx/compose/ui/text/TextMeasurer)，本轮保持连续原生输入协议，在覆盖层、样式窗口和缓存处缩减开销；理由及限制见 ADR 0016。

旧版冻结 APK：代码 c564a1a，SHA-256 `58B67619D7BC8FF7D22D53F694D9B88AA47DA327F9B542952913DC5D4763DB72`。使用相同模拟器、正好十万 Unicode 码点的标题 / 粗斜体 / 链接 / 任务 / 引用样本，等待解析完成，从同一顶部起点运行三轮。测试记录标签动作到目标正文首次 OnDraw，包含调度 / Compose / 布局；不是 GPU 时间、稳定帧率或真机数据。

最终对照于 2026-11-27 在相同 AVD、标准动画倍率、无并行构建下重跑。每个方向取三次：

| 方向 | 旧版中位数（范围）ms | 最终版中位数（范围）ms |
| --- | ---: | ---: |
| 源码 → 排版 | 1838（1790–1980） | 1297（635–1441） |
| 排版 → 阅读 | 354（134–533） | 38（37–97） |

| 排版 → 源码 | 263（29–274） | 259（259–261） |

排版 / 阅读往返复用相同转换结果，避免仅只读状态变化时重跑全文替换；空查询不扫描全文，正则从逐标记 / 逐行反复编译改为复用，同前缀宽度缓存，折叠范围使用二分查询。源码进入格式视图仍有全文布局开销，不能把这一方向描述成几十毫秒。原始日志在忽略目录 `.local/final27-baseline-switch.log`、`.local/final27-delivery-view-switch-benchmark.log`；此前试验数值不作为交付数据。

原生连续输入仍会布局全文，首次格式布局与首次表格测量并未完全虚拟化，不能宣称消除所有长文卡顿。表格 / 图片及表格行仅组合视口附近内容，行内样式窗口化，表格几何和共享 LRU 在模式往返中复用。
