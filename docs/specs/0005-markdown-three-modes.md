# Markdown 三视图与日常写作

- 来源：2026-11-02 用户确认的完整计划。
- 状态：开发版已接入；验收与真机交付以任务 0026 和 status 为准。

## 模式与语法

源码负责精确原文编辑；排版采用同一连续文本框的实时预览，当前编辑行显露结构标记，相关行内节点在光标、选区或组合涉及时显露标记；阅读用原生只读文本审阅，可选择复制和查找。模式切换不改源码，按源码块及块内像素偏移恢复视口。页签采用 16sp 标签及 Lucide 图标，文字与图标整体居中；触摸目标、按压圆角与选中指示器共用等宽边界。英文长标签在空间不足时自适应为 Code / Write / Read，再不足时图标文字纵向居中，保留完整无障碍名称。三种模式底部字数 / 路径行统一至少 48dp 高度。阅读底部空白区域可切换应用控件的显示，系统栏保留，返回优先退出沉浸。

支持 H1–H6、粗斜体、删除线、列表 / 嵌套 / 任务、引用、链接、代码、分隔线、表格。软换行在排版和阅读显示换行。HTML、图片及其他不支持内容保留原文，不下载资源。代码等宽；表格横向浏览，排版中可原位展开源码，不提供单元格编辑器。

## 工具与输入

源码与排版共用三组工具：文本（标题、粗体、斜体、删除线、链接）5 项；段落（列表、引用、增加缩进、减少缩进）4 项；插入（行内代码、代码块、分隔线、表格）4 项。工具图标及菜单条目前置图标全部来自固定上游版本的 Lucide；标题菜单为正文与 H1–H6，列表菜单为无序 / 有序 / 任务 / 取消。

工具至少 48dp 触摸目标，同行均匀居中，极窄窗口横向滚动。键盘打开且正文聚焦时工具栏直接位于键盘上方，隐藏字数路径及工具组入口；下方常驻当前工具组名称与序号。键盘收起时底部三个组入口控制显示：点击当前组收起，再点击展开，点击其他组展开并切换；标签放不下 48dp 时以对应 Lucide 图标呈现，保留完整名称与提示。工具栏左右滑动只在松手后切到相邻组，240ms 横移动画、不跟手，边界不循环；正文选区和焦点保持，过渡期间阻止重复操作。

标题 / 列表菜单直接锚定工具按钮上沿，4dp 间隔，菜单 4dp 内边距；可用高度不足时菜单内部滚动，不预留隐藏的信息行或键盘高度。不拿走正文焦点，显示当前格式状态，长按显示名称提示；链接对话框预填选区或已有链接。

格式命令不重排整篇原文。行内操作跨段分别应用，遇到代码、表格或未知受保护结构整次拒绝。混合选区统一相应格式，已有相同外层格式可取消。链接不能跨段；代码围栏大于内容中的最长反引号串。每次命令、勾选、结构回车、替换全部均为一个可撤销单元，恢复选区。

排版普通回车保留单 LF；标题后进入普通正文，列表继续同类项，新任务未完成，有序项使用下一编号但不重写后续项；空项退出一层，空引用退出一层。起点退格先取消当前层级结构，保留外层容器；批量粘贴不自动续写。源码模式保持直接输入行为。

## 查找、导出与生命周期

字面查找，默认区分大小写，可切换；编辑模式搜索源码，阅读搜索可见文本。编辑提供替换当前及全部，超限整体拒绝。延迟链接与替换命令使用执行修订防止旧偏移写入。

Markdown 默认导出 `.md` / text/markdown；另有 `.txt` / text/plain 原文副本，两者均不剥离 Markdown 标记。保留原有固定分享副本、下载发布与 SAF 取消 / 失败语义。

阅读使用最新内存正文，保留保存失败反馈及导出；无编辑工具，不允许任务勾选。进入阅读请求保存，失败不切换到旧磁盘内容。三模式共用有界会话历史与既有保存屏障，不承诺进程死亡后恢复撤销和候选。
