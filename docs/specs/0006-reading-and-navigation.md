# 行距、文稿视图与长文导航

- 状态：开发版已接入；验证及真机人工边界见[任务 0042](../tasks/0042-reading-and-long-document-navigation.md)。
- 来源：2026-11-16 用户需求。

## 全局排版

文稿更多菜单的正文大小下方增加行距：宽 / 中 / 窄，沿用等宽三段、选中字重及单个滑动衬底。默认中，18sp 字号下分别为 39 / 33 / 27sp，随正文大小同比变化。两类文稿的编辑 / 排版 / 阅读，以及回收站原文预览均使用该全局字号与行距；不改变 UI 和最近卡片摘要的字号。英文使用 W / M / N，保留 Wide / Medium / Narrow 完整无障碍名称，避免大字号拆词。偏好持久化失败沿用原有可见错误路径。

## 纯文本双视图与位置接续

纯文本提供编辑 / 阅读两页签，布局与 Markdown 三页签一致，使用同一连续正文、选区与会话历史。阅读不可输入、替换或撤销，仍可选择、复制、查找，隐藏键盘及编辑工具；返回编辑可继续输入。切换保留视口，不重新读取磁盘正文。

只读保护针对正文变更，不拦截长按、拖动选区和复制。连续输入框的输入转换器同样会收到选区手势，正文未改变时应保留选区更新；不可通过无条件撤销输入转换来实现阅读锁定。

两种文稿均静默记录最后停留的视口，阅读和编辑都更新。重开恢复最后视图及其视口，不用旧光标位置替代阅读进度。位置独立于正文与 ZIP，不提供通知；异常元数据回退到有效位置，不影响正文打开 / 保存。数据边界及异常退出限制见 [ADR 0015](../adr/0015-document-viewport.md)。

## 长文导航

默认右侧；设置 → 文稿编辑 → 导航控件位置，可全局改为左侧。边距提供标准 / 加宽：默认标准，加宽使正文区两侧及控件各内缩 16dp。导航为正文覆盖层，不占顶栏、信息行或键盘空间，不随显隐改变正文宽高。

- 可滚动距离达到视口高度的 3 倍（总长约 4 屏）才提供 Fast Scroller，短文无控件。
- 默认完全隐藏，仅正文快速长距离拖动 / 惯性滚动唤起。检测窗口为 800ms，累计位移至少约 45% 视口；程序恢复位置、光标自动滚动、侧边单点或尝试拖动边缘均不唤起。
- 停止快速滚动 / 手柄操作约 3 秒后隐藏，手柄按下与拖动期间保持显示。隐藏时没有触摸接收器。可见时只有手柄处理拖动，宽 48dp、高至少 48dp；轨道不处理点按或拖动，不支持点击位置跳转，也不提供无障碍进度跳转动作。无障碍保留名称和当前百分比，正文仍提供标准滚动动作。
- 删除回顶与回底按钮。拖动请求合并为最新目标，不累积旧定位，不移动编辑光标、不改正文。
- Markdown 排版 / 阅读共用连续滚动状态及源码锚点，不再使用独立阅读块高度估算。窗口化覆盖层、样式和缓存及全文布局限制见 ADR 0016。

## 验收

覆盖两类长 / 短文、单个长段落、所有视图往返、只读动作、行距 / 字号变化、文稿重开与 Activity / 冷进程恢复、实际手柄拖动、轨道点按无效、快速唤起 / 静置隐藏、两侧布局、中英文 320dp / 200% 字号。长文输入与真实持续阅读舒适度交由真机人工验收。

## 正文边缘羽化

2026-11-16 用户已确认交互预览并授权正式实施。源码 / 排版 / 阅读及纯文本两视图移除视图栏与正文之间的分隔线；设置 → 文稿编辑 → 正文边缘羽化，默认开启，可全局关闭并持久化。

仅在仍有正文可滚动的方向绘制 24dp 渐隐，距首尾不足 24dp 时长度随剩余距离减小；文首 / 文末对应方向归零，短文两侧都无羽化。正常正文区域过小时不让两个渐隐区重叠。正文与颜色主题相融合，滚动条、顶栏及信息行保持清晰；绘制层不接管触摸、焦点、选择或原生输入。

五视图都按完整正文滚动视口的上下边界绘制，视口底部直接衔接 Markdown 工具 / 信息行；不在滚动框外保留垂直 padding 或绘制纯色横条。正文的自然首尾留白由完整行高提供，包括段落、图片与表格覆盖层，不添加透明离屏视口。滚动状态仅在绘制阶段读取，渐变刷按尺寸 / 配色缓存，不把逐像素滚动带回全文重组。初版见 [0045](../tasks/0045-document-edge-fade.md)，边界修正见 [0049](../tasks/0049-editor-viewport-selection.md)。

## 行尾光标与正文选区菜单

软换行上一行最右侧点按采用上一行行尾的视觉光标，正文偏移仍与下一行行首相同，不插入换行或空白。原生光标及下方“文本插入手柄”（cursor / insertion handle）共用该位置；手柄可继续拖动，范围选择两端称为“选区手柄”（selection handles）。显示映射只处理完整 Unicode 码点，不进入保存 / 复制 / 撤销；手柄拖动期间保留，正文滑动或取消不清除行尾视觉位置。仅完成短点触才提交新视觉位置，范围选择、输入、组合输入、失焦及切视图继续按编辑状态清理。输出映射变化不得冒充正文编辑隐藏原生手柄，局部框架修正见 [ADR 0017](../adr/0017-native-caret-observer.md)。

正文菜单限定为可用的剪切、复制、粘贴、全选；阅读仅保留不修改正文的动作。按钮使用应用主题及字体、内容居中，窄屏可横向滚动；不加入系统文本分类或第三方 PROCESS_TEXT 项。切换视图、返回和卸载对应正文视图时关闭菜单，不允许旧菜单再访问已移除的布局坐标。菜单采用原生选区 / 剪贴板动作；Markdown 阅读正文复制额外展开表格占位，不改变单元格自己的复制选区。
