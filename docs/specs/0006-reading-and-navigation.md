# 行距、文稿视图与长文导航

- 状态：开发版已接入；验证及真机人工边界见[任务 0042](../tasks/0042-reading-and-long-document-navigation.md)。
- 来源：2026-11-16 用户需求。

## 全局排版

文稿更多菜单的正文大小下方增加行距：宽 / 中 / 窄，沿用等宽三段、选中字重及单个滑动衬底。默认中，18sp 字号下分别为 39 / 33 / 27sp，随正文大小同比变化。两类文稿的编辑 / 排版 / 阅读，以及回收站原文预览均使用该全局字号与行距；不改变 UI 和最近卡片摘要的字号。英文使用 W / M / N，保留 Wide / Medium / Narrow 完整无障碍名称，避免大字号拆词。偏好持久化失败沿用原有可见错误路径。

## 纯文本双视图与位置接续

纯文本提供编辑 / 阅读两页签，布局与 Markdown 三页签一致，使用同一连续正文、选区与会话历史。阅读不可输入、替换或撤销，仍可选择、复制、查找，隐藏键盘及编辑工具；返回编辑可继续输入。切换保留视口，不重新读取磁盘正文。

两种文稿均静默记录最后停留的视口，阅读和编辑都更新。重开恢复最后视图及其视口，不用旧光标位置替代阅读进度。位置独立于正文与 ZIP，不提供通知；异常元数据回退到有效位置，不影响正文打开 / 保存。数据边界及异常退出限制见 [ADR 0015](../adr/0015-document-viewport.md)。

## 长文导航

默认右侧；设置 → 文稿编辑 → 导航控件位置，可全局改为左侧。导航控件边距提供标准 / 加宽：默认标准，加宽使正文区两侧各内缩 16dp，控件同幅内缩，避免覆盖正文。滚动条及两个跳转按钮的可见中轴一致（距当前正文容器边缘 12dp），48dp 触摸区域不变。快速滚动条与两个跳转按钮在同一侧，正文区内布局，不侵占顶栏 / 信息行 / 键盘；提供至少 48dp 触摸目标及无障碍名称 / 进度动作。

- 可滚动距离达到视口高度的 3 倍（总长约 4 屏）才显示 Fast Scroller；仅一屏或短文隐藏。
- 快速滚动条允许按住拖动或点按轨道定位；停留阅读仍可见，降低对比度，滚动 / 拖动时增强。连续拖动合并为最新请求，不累积旧跳转，不移动光标或修改正文。
- 离顶部超过 1.5 个视口才显示回顶；离底部超过 1.5 个视口才显示回底，分别判断，接近两端自动隐藏对应按钮。可滚动范围不足一屏时全部隐藏。
- Markdown 阅读使用各块的初始换行高度估算并逐块替换为实测高度，包含单个长段落和末尾留白；滚动条反映近似进度，首尾按钮到达真实边界。不为滚动条一次性渲染 / 测量整篇正文。

## 验收

覆盖两类长 / 短文、单个长段落、所有视图往返、只读动作、行距 / 字号变化、文稿重开与 Activity / 冷进程恢复、实际拖动与无障碍进度、两侧布局、首尾隐藏、中英文 320dp / 200% 字号。长文输入与真实持续阅读舒适度交由真机人工验收。

## 正文边缘羽化

2026-11-16 用户已确认交互预览并授权正式实施。源码 / 排版 / 阅读及纯文本两视图移除视图栏与正文之间的分隔线；设置 → 文稿编辑 → 正文边缘羽化，默认开启，可全局关闭并持久化。

仅在仍有正文可滚动的方向绘制 24dp 渐隐，距首尾不足 24dp 时长度随剩余距离减小；文首 / 文末对应方向归零，短文两侧都无羽化。正常正文区域过小时不让两个渐隐区重叠。正文与颜色主题相融合，滚动条、跳转按钮、顶栏及信息行保持原样；绘制层不接管触摸、焦点、选择或原生输入。

输入框按内部可滚动边界绘制（保留原 16dp 垂直内边距），Markdown 阅读按整篇 LazyColumn 的可视边界绘制；包括段落、图片与表格覆盖层，不添加透明离屏视口。滚动状态仅在绘制阶段读取，渐变刷按尺寸 / 配色缓存，不把逐像素滚动带回全文重组。任务与实际验证见 [0045](../tasks/0045-document-edge-fade.md)。
