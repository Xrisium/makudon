## 技术化错误提示：建议改写，不能直接删掉

| 位置 / 资源 | 当前原文 | 建议方向 |
| --- | --- | --- |
| 超限 `error_too_large` | 内容不能超过 10 万 Unicode 码点或 1 MiB；此次编辑或导入已完整拒绝。 | 简化为“内容超过 10 万字符或 1 MiB，未应用此次更改。” 具体码点计数规则可放帮助文档。必须保留更改未生效的事实。 |
| 读取错误 `error_corrupt` | 工作区或文稿无法读取，已停止写入。请重试，未用空稿替换。 | “无法读取文稿库或文稿，已暂停保存。请重试。” “未用空稿替换”像开发验收声明。 |
| ZIP 异常 `backup_invalid_archive` | ZIP 损坏、加密或目录结构异常，无法恢复。请检查重复路径、文件与目录重名、绝对路径及路径穿越。 | 保留第一句；后半段含“路径穿越”等实现术语，普通用户无法据此解决。可引导换用未加密 ZIP，详细检查项放帮助文档。 |
| 恢复清理错误 `backup_done_cleanup` | 操作已提交，但部分私有材料清理未完成。可返回备份与恢复页面重试清理。 | “恢复已完成，但部分临时文件未清理。请在备份与恢复中重试清理。” 应按真实操作区分“恢复 / 撤回”，不能统一伪称恢复成功。 |
| 回收站清理错误 `trash_cleanup_pending` | 操作已提交，部分私有材料尚未清理；占用空间包含待清理材料，可在此重试。 | “部分文件尚未清理，仍占用空间。请重试清理。” 保留占用空间与恢复动作。 |
| 导出失败 `file_operation_error` | 文件操作未完成，请重试或选择其他方式。原文稿和待导出副本仍保留；目标位置可能有不完整文件。 | 可缩短，但保留“目标位置可能有不完整文件”和重试指引；此处描述的是实际失败后果，不属于可无条件删除的废话。 |

## 建议保留

- 保存失败与重试 / 导出入口；删除、彻底删除及完全覆盖的实际后果。
- 卸载会丢失私有文稿、需要外部备份的提醒。
- 导入前的副本语义，避免误认为会写回源文件；可精简措辞，但不能丢掉边界。
- ZIP 冲突中的双方选择、恢复前快照与撤回后果，以及实际跳过项 / 同名副本确认。
- 回收站恢复位置失效、同名改名和不可恢复提醒；`trash_copies_hint` 关于外部 ZIP / 快照仍可能保留副本的说明有实际意义。
- 加载进度、空列表状态、读取失败与可访问性标签。筛查冗余不等于清空所有辅助文字。

## 实施结果

- 采用删除方案：空编辑器占位句、粘贴归并副标题、剪切常驻说明、四项素材技术简介。版权 / 作者 / 许可原文与素材名称保留。
- 空稿概览采用“空文稿” / “Empty document”；关闭概览时仍隐藏。
- 其余候选按表内短句同步中英文，包括剪切单复数、导入 / 导出、冲突、语言错误、ZIP 说明和完成信息、文件入口、各类失败提示。
- ZIP 清理错误的调用仅在恢复提交完成后，采用“恢复已完成，但部分临时文件未清理……”；撤回完成仍使用独立消息。保留目标位置可能出现不完整文件、重试入口与存储限制等实际后果。
- 本节记录文案实施结果，不代表所有真机异常场景均已触发验收；具体验证见任务 0036。
