## 不建议按冗余提示批量删除

- 删除 / 彻底删除 / 覆盖 / 清理确认中的对象、范围及不可恢复后果。
- 保存失败、未保存内容、目标文件可能不完整、部分清理失败等实际失败及恢复出口。
- 同名另存、无效恢复位置、图片缺失 / Markdown 不包含图片、ZIP 不支持项等影响当前选择的边界。
- “卸载应用会导致文稿丢失，请定期导出备份”是私有存储的真实数据风险，不能仅因其是说明文字就认定为无用；若用户希望移除常驻展示，需单独确认展示位置。
- 确认中的恢复快照、外部 ZIP 仍可能保留副本等说明涉及可撤回性或删除边界，和常驻机制教学不同。
