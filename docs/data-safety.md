# 文稿与隐私约定

本页是未来存储/编辑功能的实现约束，**当前没有保存或备份功能**。

首片的私有主存储方向已由用户决定，见 [ADR 0002](adr/0002-document-storage.md)；具体协议见 [设计方案](specs/0001-plain-text-editor.md)，失败与恢复用例见 [验收规范（尚未执行）](testing/plain-text-editor-acceptance.md)。工程协议尚未实现或验证。

## 保存

- 先定义 UTF-8、换行、空文件、文件名/重命名与同名冲突行为，再实现保存。
- 私有文件后端优先临时文件写完、校验、替换；不假设所有 SAF provider 支持原子重命名或相同语义。
- 自动保存必须处理连续输入与异步写入竞争，旧内容不能覆盖新内容；明确“保存中 / 已保存 / 失败”反馈。
- 正常编辑全自动保存，无常规手动保存按钮；取消按钮不取消离开前屏障、后台尽力提交、版本校验或失败时的重试 / 导出出口。
- 磁盘满、权限失效、后台切换和写入取消必须保留已提交正文、明确显示未保存状态，进程仍存活时保留最新编辑缓冲区。进程在新提交完成前被杀，只能保证恢复最后完整提交，不能承诺未落盘输入零丢失；不要将 `remember` / 内存 ViewModel 当持久化。
- 文件原子替换不提供跨多文件事务或历史备份，也不代替单写者互斥。不能将自动保存调度周期当作异常情况下的数据丢失时间上限。
- 数据迁移须有备份、回滚或恢复路径及针对失败的验证；任何破坏性修复先保护原文件。

## 导入、导出、恢复

- 通过系统 SAF 让用户选择文件/目录，不申请 `MANAGE_EXTERNAL_STORAGE`。
- 应用内导入和系统“打开方式”接收的纯文本 / `.md` 都只读源文件并创建独立私有副本；任何自动保存、恢复或导出均不得写回、截断或删除源 URI。
- 每次导入使用独立 ID；重名、重复导入和关联 Intent 重放分别处理，不能覆盖已有文稿。切换前保护未保存旧稿，失败时保留原活动会话。
- 导入采用有界读取、UTF-8 严格校验和 10 万码点 / 1 MiB 双限制；未知大小、伪装 MIME 或文件名不得绕过检查。详细规则见 [导入协议](specs/0002-import-and-file-association.md)。
- ZIP 恢复须防路径穿越、绝对路径、超大解压和同名覆盖；导出结果完整关闭后才提示成功。
- 不覆盖原文档来“消除冲突”；提供副本或可恢复选择。
- 导出与恢复要往返测试，中文、emoji、长文件名、空文件、多个目录均应保真。

## 目录复制与移动（后续功能约束）

- 用户已要求条目长按菜单；当前只有内存例图，未实现真实复制 / 移动。不得将界面动作完成提示当作磁盘数据已发布。
- 复制文稿及目录子树必须使用独立 ID，不共享会被双方保存覆盖的权威正文；同名不能覆盖。新副本须完整校验后再发布，失败不得破坏源条目。
- 剪切阶段不删除源数据；粘贴到目标成功之前，原条目和待移动状态保留。逻辑目录移动优先保留文稿 ID 和正文，仅改变受控元数据；真实持久提交 / 恢复协议仍需另行设计。
- 阻止自身 / 后代目标造成目录环；同名冲突和目标失效明确反馈。涉及正在编辑的文稿时，必须协调当前缓冲、保存队列与切换屏障，不能由文件列表绕过单写者。
- 默认采用应用私有剪贴板，不将正文或私有路径写入系统剪贴板、日志或遥测；如果未来支持对外复制内容或路径，需要单独明确用户动作和范围。

## 重命名与删除（后续功能约束）

- 当前只有内存例图。重命名只改显示名称，不改文稿 ID、类型或正文；同级冲突必须显式处理，不覆盖现有条目。
- 文件、文件夹删除前均须确认，说明名称、位置及文件夹递归子项范围；确认目标以稳定 ID 标识，执行前重新校验，不能按列表索引删除。
- 取消不改变数据或清理编辑缓冲。确认删除涉及活动文稿时，必须与单写者、保存队列和目录元数据协调，避免过期保存重新创建已删除文稿；完整持久提交及故障恢复协议须在真实功能实施前设计与验证。
- 失败不能显示删除成功；删除后清理无效选择和待剪切引用，默认新建目标失效时使用明确显示的有效位置。复制快照与源数据的生命周期分开，不能通过删除源条目破坏已发布副本。
- 当前未实现回收站、撤销删除或磁盘删除，不承诺删除恢复能力。未来恢复方案必须说明保留期限、容量、清理与异常恢复语义。

## 隐私

- 不记录正文、私人文件路径或分享 URI 到持久日志/遥测；测试资料使用合成文本。
- 当前 Manifest 无网络和存储权限；关闭旧系统备份，并以 Android 12+ extraction rules 显式排除云备份及设备迁移的数据域。这不构成对所有厂商实现行为的保证，见 [Android 官方备份说明](https://developer.android.com/identity/data/autobackup)。
- 后续提供显式导出后用户才有可控备份；正式可用版本必须清楚说明私有数据在卸载时可能丢失。
- 发布签名密钥、代理凭据、设备日志和私人测试文稿不得提交到 Git。
