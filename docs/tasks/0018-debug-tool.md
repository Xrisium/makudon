# 任务：交互式调试工具

- 状态：完成
- 用户目标与范围：提供双击可用、不会执行后立即消失的项目调试工具，简化构建、模拟器和真机安装。
- 不在范围：修改 Android 应用、自动安装依赖或改变设备使用约定。
- 相关规范：设备选择与调试约定、开发环境、Git 工作流。

## 验收条件

- 双击入口显示中文菜单，操作结束或出错后保留结果并可返回菜单；原命令行入口仍可用。
- 支持现有构建、检查、设备、模拟器、截图和日志操作；真机安装列出本次设备，仅允许选择在线真机，复用已有 APK。
- 不自动向真机安装或启动应用，不因失败自动重试；多个真机由使用者选择。

## 实施步骤

1. 保留现有 Android 脚本作为操作后端，增加交互菜单及双击入口。
2. 更新使用说明和状态；以模拟后端覆盖菜单、错误及设备选择，检查双击入口。

## 验证与交接

- 使用模拟后端验证退出、连续操作、失败后返回、唯一设备、多设备选择 / 取消、离线及模拟器排除、无效输入；均通过。
- 通过 `test-android.cmd` 实际启动菜单并读取设备列表，确认返回菜单；沙箱内 ADB 用户目录权限不足时错误可见且菜单仍可用，获得权限后设备列表正常。
- 本轮未进行任何安装、模拟器运行或真机调试；APK 身份不变。仅修改脚本与文档，未运行 Android `Check`。
