# 任务：图片缓存二级设置与阅览菜单

- 状态：完成
- 用户目标与范围：缓存管理改为二级页，目录树、长按菜单、更多信息分别控制缓存；图片阅览增加详细信息、重命名、导出、删除；调整编辑菜单顺序及新建页文案。
- 不在范围：图片编辑、网络加载、新权限、缓存容量配置。
- 相关规范 / ADR：[图片协议](../adr/0013-library-images.md)、[图片实施](0037-markdown-images.md)、[设计](../design.md)、[数据安全](../data-safety.md)。

## 验收条件

- 三个缓存开关默认开启，持久化失败保持原设置；关闭的场景绕过内存和磁盘缓存，已有缓存由统一清理操作回收，正文和原图不变。
- 缓存二级页可滚动、返回设置；清理无需确认，保持代际门控及部分失败提示。
- 图片阅览菜单复用现有信息、重命名和安全删除流程；删除前显示引用影响，删除后关闭阅览；回收站阅览保持只读。
- 两种文稿编辑菜单中查找与替换位于字号控件下方；新建页删除导入说明，使用“导入文稿”；简中像素单位和清理说明符合要求，中英对等。
