# 任务：Markdown 图片与文稿库图片管理

- 状态：已实现并完成本轮验证 / 单向交付；真机人工验收待完成
- 用户目标：导入和插入本地 JPEG / PNG / WebP，在目录、排版、阅读及查看页管理 / 查看；目录图标与缩略图二选一；两处面板预览；可清理的有界缩略图缓存。
- 不在范围：网络图片、动图播放、图片编辑 / 压缩、行内 / 表格图片渲染。
- 相关规范：数据安全、Markdown 三视图、ZIP 代际、独立回收站；引用协议见 ADR 0013。

## 验收条件

- 图片原文件保真，移动 / 重命名引用不失效；复制批次内重映射，回收站可恢复。
- 独立段落图片可插入 / 撤销 / 查看，迟到选择结果不修改错误会话。
- 目录显示偏好持久化；菜单与信息面板完整适配、居中、有界圆角预览。
- 缓存有界、按需生成，可统计 / 清理，失败不影响原图；ZIP 往返保持引用。

## 实施步骤

1. 图片模型、二进制存储、引用与旧库兼容；回收站 / 复制 / ZIP 接通。
2. 统一图片加载与缓存、插入 / 渲染 / 查看、目录设置与面板。
3. 业务 / 故障测试、Check、模拟器验收、文档及集中一次真机交付。

## 真机人工步骤

1. 完成手机端安装确认后手动打开 Makudon Dev；在 Markdown“插入 → 图片”分别从设备与文稿库插入，检查排版、阅读、撤销及缩放返回。
2. 在设置 → 目录切换缩略图 / 图标，长按图片并打开更多信息；两种模式均应保留两处居中、等比、有界的预览。
3. 在设置 → 数据管理清理缩略图缓存，再查看图片；原图和文稿应保留，缩略图按需重建。删除引用图片时应列出受影响文稿，从回收站恢复后重新显示。
4. 导出文稿与图片 ZIP，检查普通相对路径和原图字节；再验证整库 ZIP 的恢复与撤回。保留外部 ZIP 作为独立备份，不用本地快照替代。
