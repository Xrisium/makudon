# 任务：实现原生文稿工作区并在模拟器验收

- 状态：完成（开发版交付；完整 MVP 验收未完成）
- 用户目标与范围：按已确认例图直接实现 Android 应用；三标签、目录工具与长按菜单、新建 / 导入、自动保存、源码 / 排版编辑、主题和素材许可；用户明确指定本轮使用模拟器。
- 不在范围：账户、同步、网络、ZIP、完整富文本语法、字体文件选择、正式签名发布。
- 相关规范：[工作区方案](../specs/0003-workspace-and-markdown-views.md)、[编辑保存](../specs/0001-plain-text-editor.md)、[导入](../specs/0002-import-and-file-association.md)、[架构](../architecture.md)、[数据安全](../data-safety.md)。

## 验收条件

- 原生 Compose 界面遵循柔和圆角、Noto UI 500 / 正文 450、离线品牌及图标资源，默认进入最近。
- 实际创建和重开私有文稿；自动保存有版本校验、后台调度、失败反馈和离开屏障；不覆盖源 URI。
- 目录排序 / 搜索 / 选择、复制 / 剪切 / 粘贴 / 重命名 / 删除确认均可用，取消和冲突保护原稿。
- Markdown 无改动切换保留源文；支持标题与段落排版编辑，复杂语法保留并可回源码编辑。
- Check 通过，已有 AVD 安装运行、截图及进程重启 / 文件操作 / 导入导出验证有证据；明确未覆盖的真机体验与故障边界。

## 实施步骤

1. 复用现有工具链，补齐字体、品牌、Lucide / Fluent 和随包许可，建立最小目录存储与编辑状态。
2. 完成工作区、编辑器、文件出入口与目录操作，增加数据规则和保存失败 / 并发行为测试。
3. 执行构建、Lint、单元测试及模拟器功能验收；修复问题、同步文档并分类本地提交。

- 已实现原生三标签、目录工具与长按菜单、私有正文与原子目录索引、自动保存、有限排版编辑、文件出入口、多主题字体与随包许可。具体布局 / 保存协议与限制见 [ADR 0003](../adr/0003-workspace-catalog.md)。
- Check 通过：23 项 JVM 业务测试、debug 构建、严格 Lint。新增 ViewModel 2.9.0 / 协程 1.8.1 显式依赖复用已有运行能力；协程虚拟时钟仅测试使用。版本提示仅在固定版本声明文件局部排除，保留其他全部 Lint 检查。
- 按用户明确要求使用既有 API 36 模拟器，保留应用数据。29 项平台交互、10 项外部启动 / 布局审查通过，包含原生手势、完整字节、源码保真、递归删除、导入导出、外部打开 / 重建和长文边界。设备、APK 身份、证据与未覆盖项见 [验收记录](../testing/2026-10-25-workspace.md)。
