# 任务：目录长按菜单与条目操作设计

- 日期：2026-10-25。
- 状态：完成（交互例图与设计规范；Android 未实现）。
- 用户目标与范围：提示改为搜索框下方单行纯文本，删除目录新建操作卡片和行尾省略号；长按文件 / 文件夹呼出详情、复制、剪切、粘贴菜单，文件夹另含新建目录和文稿。
- 不在范围：Android 功能、真实系统剪贴板 / 文件 I/O、设备操作或 push。
- 相关规范：[界面](../specs/0003-workspace-and-markdown-views.md)、[数据安全](../data-safety.md)、[Git](../git-workflow.md)。

## 验收条件

- 提示精确为“选择文件夹可更改新建位置，长按显示更多”，无图标、容器底色或“当前”路径，搜索展开时位于输入框下方。
- 目录无新建卡片和行末“…”；按住条目、桌面右键或键盘菜单键可打开菜单，短按行为保留。
- 文件与文件夹按类型展示动作；粘贴目标明确，同名不覆盖，剪切只在成功粘贴后移动，不允许循环目录。
- 所有内容和剪贴板仅存在示例内存中，不读写真实用户数据。

## 实施步骤

1. 调整提示和目录行样式，制作长按浮层及详情。
2. 接入示例内存复制 / 剪切 / 粘贴和失败状态，检查触控 / 键盘 / 窄屏。
3. 同步设计及安全边界，检查并本地提交。

## 验证与交接

- 交付：搜索框下方精确单行提示，无底色 / 图标 / 当前路径；目录行无省略号或新建操作卡片。长按文件四项、文件夹六项菜单，包含详情和私有内存剪贴板动作。
- 浏览器：Chrome 按住 500ms 后松手保持菜单、未误开文稿；移动手势取消长按。右键、Shift+F10、菜单方向键 / Escape、关闭后焦点恢复通过。
- 复制移动：验证独立副本名与重复粘贴、修改副本不改变原文、剪切保留源、成功移动保持 ID、目标同名拒绝移动并保留源和剪切状态、阻止后代目标、文件夹复制后子目录也使用独立 ID、新建目标和根目录保护。详情显示示例类型 / 路径 / UTF-8 字节和码点数。
- 布局：人工查看目录、文件 / 文件夹菜单、详情、深浅主题及 288px 内容宽度截图；单行提示无溢出，菜单限制在手机容器内，无脚本异常。
- 隐私：未访问系统剪贴板，复制的正文 / 名称不进入宿主状态；剪贴板和目录变化只在内存中，刷新即失，不代表真实文件操作。
- 文档：同步设计、产品、路线图、状态与后续复制移动安全约束；旧任务保留历史方案，当前规范替代行末菜单和提示横幅。
- 本轮不改 Android / 资源 / 构建，不运行 Check / Run、无设备操作或新 APK；项目文档差异空白和本地链接检查后按约定本地提交，不 push。
