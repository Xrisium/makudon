# 任务：本地回收站

- 状态：实现与本轮验证完成，真机人工验收待完成
- 用户目标与范围：保留“删除”名称；设置页“数据管理”组并列备份与恢复、回收站，显示顶层项数与磁盘总占用；不自动清理；支持文稿只读预览、整目录及目录内单项恢复、复选恢复 / 彻底删除和清空。
- 恢复规则：优先有效原位置，失效后确认恢复到根目录；同名独立恢复、不覆盖或合并。ZIP 和整库快照切换不改变独立回收站。
- 不在范围：找回旧版已删除内容、自动过期、外部源文件删除、安全擦除、自动推送远程。
- 相关规范 / ADR：data-safety、architecture、device-policy；新增 ADR 0008 记录跨索引事务。

## 验收条件

1. 单项 / 批量删除仍显示“删除”，确认明确名称、位置、递归范围及可以从回收站恢复。
2. 删除与恢复经过保存屏障、IO 互斥；重启和提交结果不确定时按持久事务凭据协调两个索引，不丢稿、不重复恢复。
3. 文件夹结构和空目录保留；可单独恢复其中的文稿，剩余结构仍能浏览；恢复保留正文、时间和上一保存版本。
4. 原位置失效须确认根目录恢复；同名不覆盖；预览只读。彻底删除和清空二次确认，清理失败有明确反馈与重试。
5. ZIP 不含回收站；恢复 / 覆盖 / 撤回不切换回收站。旧工作区兼容载入，无新权限或依赖。
