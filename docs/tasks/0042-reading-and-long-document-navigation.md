- 状态：开发与 Agent 交付完成；真机人工验收待完成
- 目标分支：main（开始时干净，串行开发）
- 用户目标与范围：全局宽 / 中 / 窄行距；纯文本编辑 / 阅读热切换；静默恢复最后停留位置；左右可配置的长文快速滚动与回顶 / 回底；最终单次真机交付并新增两篇合成长文。

## 验收条件

- 行距位于正文大小下方，交互沿用三段控件；默认中档保持原行高，影响纯文本及 Markdown 所有视图。
- 纯文本两视图共用正文与会话，阅读不可编辑；切换及重开保留最后视口。
- 位置以文稿 ID 和库代际隔离，后台 IO 静默记录，不修改正文或最近修改时间，不进入 ZIP；异常位置回到有效范围。
- 长文显示可拖动滚动条；顶 / 底按钮仅在相距至少约一屏半时分别显示；短文隐藏；默认右侧，可切至左侧，触摸与无障碍均可操作。
- 模拟器覆盖持久化、只读、视图 / 行距切换、长短文、导航与左右布局，检查中英文小屏大字号。
