# 任务：纯目录 ZIP 备份与恢复

- 状态：完成（真机人工验收待用户）
- 用户目标与范围：整库纯目录 ZIP 导出、电脑创建的标准 UTF-8 `.md/.txt` ZIP 导入；单独保存（默认）/ 增量更新 / 完全覆盖；逐项冲突与最近一次恢复前快照。
- 不在范围：同步、正文自动合并、附件、清单格式、应用设置备份、网络和存储权限扩展。
- 相关规范 / ADR：data-safety、architecture、device-policy；新增 ADR 0006。

## 验收条件

1. 三种模式顺序、默认值及辅助说明与用户确认一致；破坏性操作二次确认。
2. 正文及目录往返保真，源 URI 不变；异常 ZIP 不发布，增量不删除本地独有内容，冲突逐项确认。

4. Check 与模拟器专项 / 原有回归通过后集中单向交付真机一次，人工验收另记。

3. 接入保存协调、SAF、恢复预览与设置入口，补充模拟器回归。
