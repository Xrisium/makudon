# 任务：启动产品页

- 状态：完成（真机人工体验待验；用户要求本轮不安装真机）
- 用户目标与范围：按已确认预览，大图形 LOGO 上、Makudon 路径字标下，组合相对整屏居中，使用当前应用主题。
- 不在范围：人为启动延时、新字体或依赖、存储格式变更。
- 相关规范：设计原则、架构、设备策略。

## 验收条件

- 冷启动读取已保存主题后显示同主题产品页；系统主题随系统明暗选择。
- 语言初始化和库主题读取完成后才允许应用首帧，剩余加载显示品牌页；准备完成立即进入工作区，失败保留提示和重试。
- 横屏、小屏和字体放大时保持组合居中且不裁切；不修改原始图标路径。

## 实施步骤

1. 从现有品牌矢量拆出图形和字标，接入全屏加载组件。
2. 在既有库加载锁内发布已读取主题，首帧门控避免错误主题闪现。
3. Check、模拟器专项与回归；用户随后明确禁止本轮真机覆盖安装，取消真机交付。

## 验证与交接

- 实现：图形可视宽 166dp，字标宽 190dp，中间 30dp；整组在 edge-to-edge 窗口中心，矮屏同比缩小。路径来自已集成品牌素材，TalkBack 合并读出品牌与加载状态。
- 主题：原 `LibraryController.load()` 返回后，在同一 IO 互斥区内发布主题，再继续回收站校验。MainActivity 的首帧门控等待语言 / 主题，MakudonApp 仅在初始库尚未就绪且无错误时显示产品页。没有新的主题权威、索引字段、主线程文件 I/O 或展示延时。
- 限制：Android 自带启动画面仍先显示并受系统管理；不能在读取应用主题前显示自选配色。快速启动可能直接进入工作区，不保证产品页停留时长。其他 API 和真机尚未验证。
