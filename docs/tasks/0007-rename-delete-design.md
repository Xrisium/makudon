# 任务：目录条目重命名与删除确认例图

- 状态：完成
- 用户目标与范围：在可交互例图的文件、文件夹长按菜单中加入重命名和删除；删除必须确认；同步设计文档并本地提交。
- 不在范围：Android 功能、真实文件读写、回收站或持久恢复、构建和设备操作。
- 相关规范 / ADR：[视觉原则](../design.md)、[导航设计](../specs/0003-workspace-and-markdown-views.md)、[数据安全](../data-safety.md)、[Git 约定](../git-workflow.md)。

## 验收条件

- 文件和普通文件夹均可重命名；检查空名称、无效字符、同级重名，文件类型后缀不可误改。
- 删除先显示条目名称、位置；文件夹另提示包含的子目录和文稿；取消不修改任何条目。
- 确认后只删除例图中的目标与后代；选择位置、最近列表和待剪切状态保持有效，不影响其他正文。
- 长按、右键与键盘操作可用，深浅主题及窄屏不裁切关键动作。

## 实施步骤

1. 已从上一版派生独立交互例图，文件菜单六项、文件夹菜单八项，加入重命名输入和删除确认。根文稿库为受保护的虚拟位置；收件箱删除后从最近新建显式回退根目录。
2. 已检查冲突、取消、递归删除、剪贴板及空列表边界，并查看深浅主题和窄屏实际渲染。
3. 已同步设计、产品、数据安全、路线图与状态文档，按约定单独本地提交本次文档，不推送。
