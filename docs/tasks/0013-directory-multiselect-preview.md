# 任务：目录复选机制设计与预览

- 状态：最终预览已获用户认可并授权实现；原生功能及验收已完成，见[任务 0014](0014-native-multiselect-and-clipboard.md)。下文保留设计阶段范围与预览依据。
- 用户目标与范围：设计适合手机目录树的复选机制，先提供可交互效果，再由用户决定是否实施。
- 不在范围：修改原生目录选择状态、增加真实批量复制 / 移动 / 删除、需求 5–6 图标修改、设备安装。
- 相关规范 / ADR：任务 0012、设计原则、数据安全、ADR 0003 / 0004。

## 当前交互方案

1. 正常浏览不常驻复选框，唯一入口为条目长按菜单中的“复选”，进入时勾选该项；从根目录菜单进入则不预选根目录。保留原菜单的已有动作，根目录不参与批量操作。
2. 普通目录页保留已认可的标题、五个工具按钮、提示与底部导航。进入复选后按用户标注图单独切换为左上角 X、中间“已选 N 项”、右侧“清空选择”，其下直接接目录树；删除搜索、选择可见项、第二个清空按钮及递归提示所占区域。清空只取消勾选，界面退出统一由左上角 X 控制；不保留“完成”或菜单退出入口。
3. 用户已选择行尾复选框，保留左侧箭头、文件夹图标与缩进；移除前置方案和方案切换控件。
4. 显式勾选文件夹表示整个文件夹及后代一起处理，后代显示继承的勾选态，不能单独排除；先取消父级，再选子项。勾选父级时移除重复的显式子项。只有后代被独立勾选时，父级显示半选；点击半选会选中整个文件夹。根目录不显示半选框。
5. 顶部计数以去重后的操作根条目为准，半选父级不计数。整行短按勾选 / 取消，不打开文稿、不改变新建位置；箭头独立展开，收起不丢失勾选。递归范围在删除确认中说明，不恢复被删除的顶部提示区域。进入复选时关闭普通搜索，展示目录树。
6. 底部使用“复制 / 剪切 / 粘贴 / 删除”四个同风格图标操作。复制、剪切、删除在零选择时禁用；粘贴只依赖剪贴板是否有效，不依赖勾选数。底部仅以次级文字显示剪贴板或操作反馈，复选长按菜单可调用同样四个动作，不再提供全选或退出。
7. 单项菜单与底部操作共用一份应用私有剪贴板和同一组处理函数。复制捕获独立快照，可重复粘贴，源删除不影响副本；剪切只记录稳定源 ID，粘贴前保留源，成功后才清空剪贴板，取消 / 失败保留。新复制 / 剪切替换旧内容；清空选择或 X 退出均保留剪贴板。删除待剪切源时清理失效引用，保留仍有效的其他源。
8. 普通单项菜单粘贴沿用原规则：文件夹为自身、文稿为所属目录。复选底部粘贴按下节归并并确认唯一目标；粘贴内容始终来自统一剪贴板，当前勾选仅用于推断目标。删除单独确认名称、位置和递归范围，默认焦点为取消，说明无法恢复。界面内退出仅 X，Escape 只关闭菜单 / 确认；重建只恢复有效 ID，不自动执行待处理动作。

## 多项被选中时的粘贴建议

- 先将每个选中文稿映射为所属目录、选中文件夹映射为自身，再按稳定目录 ID 去重；和剪贴板内有几项分别计算，不把当前选中项当作粘贴来源。
- 归并后只有一个目标时，直接采用它并在确认页明确显示位置；多个同目录文件不会产生重复询问或重复粘贴。零选择时建议原新建位置，仍可改选。
- 若跨目录 / 跨层级形成多个目标，显示“选择一个粘贴位置”，列出相关目录、不同于候选的共同上级，以及可展开的其他文件夹。无默认勾选、确认按钮初始禁用；用户明确选定一个位置后，一次只粘贴到该位置。不能擅自向每个选中项的所在目录重复分发，不能静默采用共同上级。
- 确认页单独显示“剪贴板 · 复制 / 剪切 N 项”及来源名称，和目标候选分区；取消不改变勾选、文件或剪贴板。屏蔽自身 / 后代目标、失效源与移动同名冲突，并明确原因；不覆盖已有内容。

## 已采用的实施计划

1. 先落地单独的复选状态与规范化规则，和“新建目标目录”状态分离；以稳定 ID 选取，目录变化时清理失效项。将当前单项剪贴板扩展为规范化条目集合，单项 / 复选入口复用，避免两套剪贴板或两套粘贴语义。
2. 为批量动作补充存储层入口，发布前重新校验整批目标、权限与冲突；不能从 UI 顺序调用单项接口后声称整批成功。移动整批修改索引后一次发布；复制先完整建立独立正文、校验全部副本后一次发布；删除一次移除全部索引后清理，并明确报告清理失败。
3. 保持当前名称策略：复制按同级自动副本名且整批互相避让，移动同名冲突在发布前阻止整批；不静默覆盖、不形成目录环。移动到原父目录的条目明确显示无需移动，全部无需移动时禁用确认。
4. 补充父子去重、继承 / 半选、隐藏选项、冲突整批不发布、写入失败保留源和选择、清理部分失败等业务测试；Check 后集中安排界面验收，设备安装另遵守设备策略。

## 预览验收条件

- 普通页保持已认可样式，长按菜单进入行尾复选；模式内顶部仅 X / 数量 / 清空选择，列表紧接顶部，无红框区域控件，底部为复制 / 剪切 / 粘贴 / 删除。
- 单项与批量剪贴板互通，清空 / 退出不清剪贴板。可演示同目录目标去重、跨层级显式择一、一次粘贴到一个目标、复制重复副本、剪切成功清空及删除确认；只操作预览合成条目，不访问真实文稿。
- 覆盖 320px 窄宽、浅色 / 深色、键盘和无障碍状态；明确记录预览检查结果与待确认项。

## 验证与交接

- 默认展示已认可的普通目录页，保留长按 / 右键入口；当前新版复选外观依据用户标注图，不再沿用此前“模式内也保留工具栏 / 导航”的方案。
- Chrome / Playwright 验证通过：模式前五按钮保持原样、模式内 X / 清空唯一语义、删除区域及空白消失、底部四动作、父子去重 / 半选、同目录目标归并、跨目录跨层级目标无默认选中、默认取消焦点、一次只产生一组副本、取消保留状态、复制重复粘贴、单项 / 批量剪贴板互通、多项剪切保留 ID 且成功后清空、阻止自身 / 后代目标、删除复制源后快照仍可粘贴。
- 图标沿用宿主解析源与缓存复用；320 / 390 / 736px 浅色 / 深色及初始化函数暂不可用时重绘通过，未发现控件横向溢出、缺失 / 空图标或 JavaScript 错误。复选页、多目标位置确认及深色窄屏截图已人工查看。实际会话重呈现仍由用户确认；演示仅修改合成条目。
- 设计阶段的浏览器预览不能代替 Android 触摸、中文字体缩放和 TalkBack；当时未安装设备或接入原生批量接口。
- 用户随后认可普通目录页、行尾位置、长按入口、模式内布局及多目标显式择一方案，并授权实施。原生复选、批量事务和统一剪贴板已完成，Check、36 项 JVM 与 55 项模拟器检查通过，见[实施验收](../testing/2026-10-26-multiselect.md)。本轮手机未安装，完整 TalkBack / 真机体验仍待验收。
