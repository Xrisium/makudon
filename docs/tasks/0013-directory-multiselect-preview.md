# 任务：目录复选机制设计与预览

- 状态：已按用户选择保留行尾复选框，恢复原工具栏并将入口移至长按菜单；新版预览待确认，未实施 Android 功能
- 用户目标与范围：设计适合手机目录树的复选机制，先提供可交互效果，再由用户决定是否实施。
- 不在范围：修改原生目录选择状态、增加真实批量复制 / 移动 / 删除、需求 5–6 图标修改、设备安装。
- 相关规范 / ADR：任务 0012、设计原则、数据安全、ADR 0003 / 0004。

## 当前交互方案

1. 正常浏览不常驻复选框，唯一入口为条目长按菜单中的“复选”，进入时勾选该项；从根目录菜单进入则不预选根目录。保留原菜单的已有动作，根目录不参与批量操作。
2. 顶部标题、工具栏五个按钮的样式、顺序和功能，以及底部导航保持原状，不加入“选择”按钮，不替换为选择计数 / 退出 / 全选工具栏。进入后仅在原提示下方增加次级纯文字，说明数量、递归范围与长按批量操作。整行短按勾选 / 取消，不打开文稿、不改变新建位置；左侧箭头始终独立展开 / 收起。
3. 用户已选择行尾复选框，保留左侧箭头、文件夹图标与缩进；移除前置方案和方案切换控件。
4. 显式勾选文件夹表示整个文件夹及后代一起处理，后代显示继承的勾选态，不能单独排除；先取消父级，再选子项。勾选父级时移除重复的显式子项。只有后代被独立勾选时，父级显示半选；点击半选会选中整个文件夹。根目录不显示半选框。
5. 计数以去重后的操作根条目为准，例如“已选 2 项”；补充实际包含的文件夹 / 文稿数。半选父级不计入操作。收起目录不取消勾选；搜索过滤不清空勾选，显示隐藏的已选条目数。
6. “选择可见项”“清空选择”“退出复选”均放在复选期间的长按菜单内。树模式选中文件夹会连同未展开的后代处理，提示说明这一点；搜索仍只匹配文稿名，可见项只指当前结果。取消搜索恢复树状态。
7. 复选期间长按任意条目打开批量菜单，以“已选 N 项”为标题，提供“复制所选 / 移动所选 / 删除所选”，零选择时禁用。顶部搜索、排序、展开和新建入口均保留，底部导航不替换。复制 / 移动打开目标选择与范围确认，禁止自身 / 后代目标；删除单独确认名称、位置和递归范围，默认焦点为取消，并说明无法恢复。
8. 返回键先关闭菜单 / 确认弹层，再退出复选；菜单也可直接退出。退出清空勾选，不产生文件操作；通过原导航离开目录时退出复选，原新建位置不变。重建可保留有效 ID，重新冷启动不恢复待执行批量动作。长按 / TalkBack 均保留进入选择的明确入口，触摸热区至少 48dp，状态不只靠颜色表达。

## 若获准实施

1. 先落地单独的复选状态与规范化规则，和“新建目标目录”状态分离；以稳定 ID 选取，目录变化时清理失效项。
2. 为批量动作补充存储层入口，发布前重新校验整批目标、权限与冲突；不能从 UI 顺序调用单项接口后声称整批成功。移动整批修改索引后一次发布；复制先完整建立独立正文、校验全部副本后一次发布；删除一次移除全部索引后清理，并明确报告清理失败。
3. 保持当前名称策略：复制按同级自动副本名且整批互相避让，移动同名冲突在发布前阻止整批；不静默覆盖、不形成目录环。移动到原父目录的条目明确显示无需移动，全部无需移动时禁用确认。
4. 补充父子去重、继承 / 半选、隐藏选项、冲突整批不发布、写入失败保留源和选择、清理部分失败等业务测试；Check 后集中安排界面验收，设备安装另遵守设备策略。

## 预览验收条件

- 仅保留行尾排布；从长按菜单进入 / 退出复选，工具栏与底部导航在前后保持一致。整行勾选、独立箭头、父子去重、半选与继承、搜索保留选择和菜单批量动作均可操作。
- 可打开复制 / 移动目标确认与删除确认；只演示合成内容的操作范围和目标，不访问应用目录或执行真实文件操作。
- 覆盖 320px 窄宽、浅色 / 深色、键盘和无障碍状态；明确记录预览检查结果与待确认项。

## 验证与交接

- 默认展示原目录页，从触摸长按 / 桌面右键菜单中的“复选”进入；长按复选条目打开批量动作和退出选项。用户明确要求恢复原工具栏，已移除此前预览的顶部选择入口、替换工具栏和底部批量工具栏。
- 最新 Chrome / Playwright 检查通过：五按钮工具栏和底部导航在复选前后的结构、文字与图标一致；菜单独占入口、触摸长按、行尾位置、继承 / 半选 / 父子去重、搜索隐藏计数、菜单全选 / 清空 / 退出、无效移动目标、删除范围、确认默认取消焦点与 Escape 关闭均正常。
- 图标沿用已修正的宿主解析源与缓存复用；最新检查覆盖初始化函数暂不可用时的菜单、搜索与复选重绘，未发现缺失 / 空图标或 JavaScript 错误。320 / 390 / 736px 的浅色 / 深色及菜单边界检查通过，截图已人工查看。实际会话重呈现仍由用户确认；预览仅使用合成数据，不读取或修改真实文稿。
- 浏览器预览不能代替 Android 触摸、中文字体缩放和 TalkBack；这些设备验收尚未执行。无新增依赖、无设备安装、无原生批量接口。
- 行尾位置与保留原工具栏已由用户确定；当前仍仅提供新版预览，待用户进一步确认后才开始原生实现。
