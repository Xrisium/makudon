# 任务：目录复选机制设计与预览

- 状态：设计与交互预览完成，等待用户决定，未实施 Android 功能
- 用户目标与范围：设计适合手机目录树的复选机制，先提供可交互效果，再由用户决定是否实施。
- 不在范围：修改原生目录选择状态、增加真实批量复制 / 移动 / 删除、需求 5–6 图标修改、设备安装。
- 相关规范 / ADR：任务 0012、设计原则、数据安全、ADR 0003 / 0004。

## 推荐交互

1. 正常浏览不常驻复选框。标题右侧提供“选择”；长按现有菜单增加“选择多项”，进入时勾选该项。根目录只能展开，不参与批量操作。
2. 进入后顶部显示“已选 N 项”和退出按钮；整行短按勾选 / 取消，不打开文稿、不改变新建位置。左侧箭头始终独立展开 / 收起。退出后恢复原新建位置与展开状态。
3. 推荐复选框置于行尾，保留左侧箭头、文件夹图标与缩进的位置；另提供前置复选框对照，便于比较层级与点击距离。
4. 显式勾选文件夹表示整个文件夹及后代一起处理，后代显示继承的勾选态，不能单独排除；先取消父级，再选子项。勾选父级时移除重复的显式子项。只有后代被独立勾选时，父级显示半选；点击半选会选中整个文件夹。根目录不显示半选框。
5. 计数以去重后的操作根条目为准，例如“已选 2 项”；补充实际包含的文件夹 / 文稿数。半选父级不计入操作。收起目录不取消勾选；搜索过滤不清空勾选，显示隐藏的已选条目数。
6. 使用“选择可见项”代替范围含糊的“全选”，另有“清空”。树模式选中文件夹会连同未展开的后代处理，提示始终说明这一点；搜索仍只匹配文稿名，可见项只指当前结果。取消搜索恢复树状态。
7. 选择期间底部导航替换为“复制 / 移动 / 删除”，零选择时禁用；搜索和展开继续可用，新建与排序暂时隐藏。复制 / 移动打开目标选择与范围确认，禁止自身 / 后代目标；删除单独确认名称、位置和递归文件夹 / 文稿数，默认焦点为取消，并说明无法恢复。
8. 返回键先关闭确认 / 位置弹层，再退出选择。退出选择清空勾选，恢复底栏；不产生文件操作。重建可保留有效 ID，重新冷启动不恢复待执行批量动作。长按 / TalkBack 均保留进入选择的明确入口，触摸热区至少 48dp，勾选状态不只靠颜色表达。

## 若获准实施

1. 先落地单独的复选状态与规范化规则，和“新建目标目录”状态分离；以稳定 ID 选取，目录变化时清理失效项。
2. 为批量动作补充存储层入口，发布前重新校验整批目标、权限与冲突；不能从 UI 顺序调用单项接口后声称整批成功。移动整批修改索引后一次发布；复制先完整建立独立正文、校验全部副本后一次发布；删除一次移除全部索引后清理，并明确报告清理失败。
3. 保持当前名称策略：复制按同级自动副本名且整批互相避让，移动同名冲突在发布前阻止整批；不静默覆盖、不形成目录环。移动到原父目录的条目明确显示无需移动，全部无需移动时禁用确认。
4. 补充父子去重、继承 / 半选、隐藏选项、冲突整批不发布、写入失败保留源和选择、清理部分失败等业务测试；Check 后集中安排界面验收，设备安装另遵守设备策略。

## 预览验收条件

- 两个排布方案均可进入 / 退出选择、点击整行、箭头展开、父子去重、观察半选与继承勾选、搜索保留选择及选择可见项。
- 可打开复制 / 移动目标确认与删除确认；只演示合成内容的操作范围和目标，不访问应用目录或执行真实文件操作。
- 覆盖 320px 窄宽、浅色 / 深色、键盘和无障碍状态；明确记录预览检查结果与待确认项。

## 验证与交接

- 已提供“行尾复选框 · 推荐”和“前置复选框”两种排布，默认展示选中目录和单篇文稿的状态；“完成”退出后可从“选择”重新进入，长按 / 桌面右键菜单可预选条目进入。
- 已用现有 Chrome / Playwright 验证继承勾选、半选、父子去重、收起保留、搜索隐藏计数、选择可见项、自身 / 后代目标禁用、零选择按钮禁用、长按菜单入口、递归删除范围，以及确认弹层的默认取消焦点、Tab 循环和 Escape 关闭。用户随后报告图标丢失，已修正动态重绘对初始化函数的依赖，采用宿主解析后的静态图标源与缓存复用；新增延迟初始化、初始化函数暂不可用时重绘、重复折叠、正常 / 选择 / 搜索 / 菜单 / 弹层及两种排布的图标存在性检查。上述回归均通过，无缺失 / 空图标及 JavaScript 运行错误；实际会话重呈现仍由用户确认。
- 320 / 390 / 736px 宽度和深色模式检查通过，控件无横向溢出；浅色选择、深色窄屏与删除确认截图已人工查看。预览使用合成数据，仅展示确认结果，不读取或修改真实文稿。
- 浏览器预览不能代替 Android 触摸、中文字体缩放和 TalkBack；这些设备验收尚未执行。无新增依赖、无设备安装、无原生批量接口。
- 用户需决定是否采用推荐的行尾复选框、文件夹递归与继承规则；确认后才开始原生实现。
