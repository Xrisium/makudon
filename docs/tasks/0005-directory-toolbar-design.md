- 日期：2026-10-25。
- 状态：完成（讨论例图和素材 / 规范；Android 尚未实现）。
- 用户目标与范围：更新讨论例图，最近页新建改为右上角轻量按钮；目录删除新建位置卡片、提示移到顶部，增加搜索 / 创建目录，提供展开收起和各类排序的图标差分及柔和排序菜单，Markdown 使用 Fluent 文件类型图标并管理许可。
- 不在范围：Android 功能、设备安装、真实磁盘搜索 / 创建目录、存储迁移或 push。

## 验收条件

- 默认最近，右上角图标文字按钮进入既有新建二级页，无新建卡片或“本机”标记。
- 目录顶部工具栏包括搜索、排序、展开收起、创建目录、新建文稿，保留 48px 可触区域；窄屏可换行，不靠缩小热区挤入。
- 提示位于工具栏下方，不再显示独立新建位置卡片；选中目录仍明确可见，新建二级页显示完整目标。
- 展开收起及五种排序 / 升降序具有可区分图标；菜单与主题一致，选中状态与名称清楚。
- Fluent 20px Markdown 图标来自微软固定版本，保存源 SVG、完整 MIT 和哈希，不引入整套图标依赖。

## 实施步骤

1. 核对现有例图与官方图标许可，创建可追溯素材记录。
2. 修改交互例图，检验入口、创建目录 / 搜索示意、排序与展开状态、窄屏布局和主题。
3. 同步规范与状态，分类提交素材和文档，不 push。

- 例图：最近页轻量右上角新建入口，目录去除新建位置卡片并上移提示，五工具栏、状态化图标、主题化排序浮层、名称搜索及内存目录创建均可操作；原有三标签和新建二级流程保留。
- 浏览器：Chrome 无头检查入口、工具顺序、五种排序图标与方向、整体及逐项目录展开 / 收起差分、菜单方向键 / Escape、搜索结果 / 空状态、目录父位置和空 / 非法 / 重名验证、所选目录中新建、源码 / 排版无修改切换，共用脚本无异常。
- 布局：736 / 390 / 320px 外层宽度检查，最窄 288px 内容宽度下可见元素无裁切，排序浮层处于手机容器内，五个工具按钮热区均 ≥ 48×48px；人工查看深浅主题、最近 / 目录 / 排序 / 搜索 / 创建目录截图。
- 新增提示条的次级文字在柔和背景上单独检查并微调颜色混合，五套主题实际渲染对比度为 4.89–5.69:1。
- 素材：微软原生 20×20 SVG 仅 1,024 字节，按原样提交；预览作主题色 mask，未手绘修改路径。来源、SVG / MIT 的 SHA-256、XML 画布及无脚本 / 外部引用检查通过。
- 隐私：搜索词、目录名与正文未写入宿主预览状态或仓库。创建目录、搜索、保存及导出均无真实磁盘实现。
- 文档：同步设计、产品、路线图、状态和素材许可，说明 Fluent 仅作 Markdown 类型标识，操作图标继续 Lucide。历史任务保留当时方案，当前规范以本轮为准。
- Git：素材 / 许可与界面规范分别本地提交，不 push。项目差异空白检查、本地 Markdown 链接检查通过；旧上游 OFL 许可原文的行尾空白按既有例外保留。
- 本轮不改 Android Kotlin / 资源 / Manifest / 依赖 / 构建，无 Check / Run、设备操作或新 APK；不将浏览器例图当作真机验收。
