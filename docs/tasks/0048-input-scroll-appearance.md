# 任务：表格组合输入、长文滚动与配色回归

- 状态：完成针对性修复与模拟器回归；真机人工验收及完整发布回归待完成。目标分支 `main`。
- 范围：复现并修复表格候选残留，分析与改善密集 Markdown 长文滚动，修复配色测试的不稳定性并更新报告。
- 不在范围：发布、签名、版本号变更、迁移文稿或重建输入架构。

## 验收条件

- 多次组合候选替换、解析与保存后正文无残留，保留其他单元格和撤销；在模拟器复测失败与生命周期边界。
- 同机、同负载、相同合成文稿测量优化前后，检查正文、选区和导航；不把回调间隔当作真机帧率。
- 配色测试能可靠观察真实颜色和底栏动效，不能通过放宽断言掩盖产品问题。

## 实施步骤

1. 保存复现证据和性能基线，定位输入法及滚动路径。
2. 分别实施最小修复与必要回归测试。
3. 在模拟器验证并更新测试报告、状态与交付记录。
