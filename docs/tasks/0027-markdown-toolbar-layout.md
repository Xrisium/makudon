- 三个页签的触摸目标、按压效果和选中指示器使用相同布局边界；图标文字整体居中，字号增加，小屏和大字号可用。
- 阅读与两个编辑模式的字数 / 路径行高度和位置一致。
- 三组工具分别 5 / 4 / 4 项，同组均匀分布，菜单条目有官方 Lucide 图标；菜单底边距工具栏顶边 4dp，不预留已隐藏信息行。
- 横滑只在松手后切组，保留编辑选区与键盘；点击当前组切换显示，切换其他组直接展开。
- H1–H6 工具及渲染保持可用，包含官方 heading-6 图标，不改写已有源码。
