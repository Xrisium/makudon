# 任务：Markdown 三视图与日常写作

- 状态：完成（开发版实现、模拟器验收与单次真机交付；真机人工体验待验）
- 用户目标：源码精准编辑、排版实时预览编辑、阅读只读审阅；双编辑模式格式工具、查找替换、Markdown 导出。
- 范围：常用 Markdown（含表格、任务列表、删除线），连续选区、共享撤销及局部源码修改。

1. 验证固定 CommonMark 0.24.0 及源码范围，建立同正文连续编辑与实时预览。
2. 实现格式命令、结构输入、三视图、键盘快捷栏与阅读渲染。
3. 查找替换、双格式导出、本地化、许可、ADR 与回归。
4. Check、Android 编译、模拟器专项及既有工作区回归，检查小屏大字号截图；最终集中单次真机交付。

三模式无修改切换保持字节；局部命令和撤销保持未知结构；阅读不改正文；中文组合与旧解析结果不能覆盖新输入。
