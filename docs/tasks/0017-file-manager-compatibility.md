# 任务：文件管理器优先的导入导出

- 状态：实现与模拟器完成；华为交互待系统安装阶段结束
- 用户目标与范围：文稿导入、TXT 导出、ZIP 选择恢复与 ZIP 导出共用应用选择面板；华为文件管理优先，提供分享、下载目录和系统选择器出口
- 不在范围：全盘权限、原文件持续编辑、厂商私有接口、其他品牌真机兼容承诺
- 相关规范 / ADR：数据安全、导入协议、设备约定；新增 ADR 0007

## 验收条件

- 导入先选择应用，真实名称 / 图标，华为文件管理置前；取消不触发备用应用
- 导出快照固定；失败可重试；分享不显示保存成功；异步接收不受 ZIP 暂存清理影响
- 下载目录新建独立文件，完成校验后发布，失败可见且不覆盖已有文件
- Check 和模拟器业务 / 文件交互回归通过；真机集中安装一次，仅验证文件交互

## 实施步骤

1. 实现共享文件暂存、Android 协议适配和应用选择界面，接入四个入口
2. 补充失败 / 生命周期 / 同名与快照测试，执行 Check 与模拟器验收
3. 华为单次集中安装，验证文件管理本地保存能力并记录实际结果
4. 同步 ADR、产品、状态和交付记录，审查并提交，不推送

## 验证与交接

Check（75 项 JVM 测试、严格 Lint）通过；模拟器文件交互 37 项、工作区 29 项和 ZIP 27 项通过，四张普通 / 大字号截图已查看。华为唯一一次 APK 已推送并发起覆盖安装，未返回成功，未启动新应用或安装真机测试 APK。厂商文件管理本地保存能力仍待验，当前保守显示分享入口。APK SHA-256、设备能力、剩余步骤与限制见[验收记录](../testing/2026-10-31-file-manager.md)。
