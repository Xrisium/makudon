- 文稿与文件夹信息均在刷新后显示手机当前时区的 `yyyy/MM/dd HH:mm:ss` 创建 / 最近修改时间。
- 文件夹大小为该逻辑子树所有文稿私有文件的实际字节总和（含尚存的临时 / 旧材料），不包含库级索引、回收站、整库快照或共享导出；空文件夹为 0 B。逻辑文件夹本身不创建磁盘目录，无法归属的文件系统块 / 共用索引不分摊。
- 空目录最近修改时间至少为自身创建时间；非空目录取自身及全部后代最新修改 / 创建时间。
- 信息弹窗在窄屏 / 大字号可滚动，英文和简体中文齐全。
