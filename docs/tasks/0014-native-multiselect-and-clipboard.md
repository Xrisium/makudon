## 验收条件

- 长按菜单进入；顶部仅 X / 已选数量 / 清空选择，下接目录树；底部复制 / 剪切 / 粘贴 / 删除。普通页保留五按钮布局。父子去重、继承勾选、半选、箭头独立展开，清空不退出，退出不清剪贴板。
- 单项 / 批量操作共用私有内存剪贴板；复制独立快照可重复粘贴，剪切只在成功后清空，失败和取消保留；删除清理失效剪切引用。
- 多选粘贴先归并目标，同目录直接显示唯一目标；跨目录 / 层级提供相关目录、共同上级及其他位置，初始不选，显式择一。界面区分剪贴板来源与目标，阻止自身 / 后代、同名移动、全部原位等无效操作。
- 批量复制先完整校验并创建全部新正文，再一次发布索引；移动 / 删除整批一次发布；删除清理尝试全部文稿且失败明确反馈。发布失败不显示成功，不覆盖源数据。
- 最近新建仅使用 Lucide `plus` 图标；目录对应按钮换为 Lucide `file-plus-corner`，不调整其余排布；补全素材来源与哈希。
