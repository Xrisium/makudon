# 任务：编辑视口、导航与选区修复

- 状态：修复与针对性验证完成；完整发布回归及 Harmony 测试机人工验收待完成
- 用户目标与范围：修复导航显隐、软换行行尾视觉光标、正文边缘空档、列表缩进与行距、选区菜单外部入口及对齐、选中时切换视图崩溃；核实菜单历史来源
- 不在范围：更换编辑器引擎、增加 AI / 浏览器功能、发布版本
- 目标分支：main；开始时工作区干净
- 相关规范 / ADR：0005、0006、ADR 0011、设备约定

## 验收条件

导航默认隐藏，快速长距离滚动或侧边拖动后出现，停止几秒隐藏，单点不唤起且不改排版。软换行行尾点按保持下一行行首的编辑偏移，仅改变光标显示。五视图羽化贴合正文视口；列表续行缩进且项间行距正常。正文选区菜单仅提供基础操作、文字居中；菜单显示时切换各视图不崩溃、不改正文。

## 实施步骤

1. 核实源码、提交历史和设备菜单提供者，复现选区切换异常。
2. 修正正文滚动边界与列表排版，实现导航显隐和视觉光标；约束菜单生命周期。
3. 模拟器专项验证、差异审查及集中真机交付，记录身份与未验证边界。
