# 任务：界面与正文字体设置

- 状态：实现完成；真机人工验收待完成
- 用户目标与范围：界面、正文分别选择 Noto Sans、Noto Serif、霞鹜文楷或系统字体及三档粗细；设置页与子页按确认预览呈现，预览使用指定文案和进入时本地日期。
- 不在范围：自选字体文件、联网字体、字号及文稿格式改写。
