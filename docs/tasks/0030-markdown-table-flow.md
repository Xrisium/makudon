# 任务：表格随正文纵向滚动

- 状态：开发与模拟器验证完成；已单向真机交付，人工体验待验
- 用户目标与范围：表格按内容高度展开，取消内部纵向滚动，仅保留宽表横向滚动；排版与阅读统一。
- 不在范围：行列工具、Markdown 或存储格式变更。
- 相关规范 / ADR：规范 0005、ADR 0012、设备策略。

## 验收条件

短表格不留固定高度空白；长表格在正文中完整占位，表内纵向手势滚动整篇；换行内容、字号变化与多个表格更新占位；单元格输入、保存、撤销及表后输入保持可用。

## 实施步骤

1. 为排版逐表计算内容高度，同步正文占位；可见行挂载原生单元格，纵向手势共用正文滚动。
2. 移除阅读表格的高度上限与内部纵向滚动。
3. Check、模拟器专项与回归、截图检查，更新文档并单次真机交付。
