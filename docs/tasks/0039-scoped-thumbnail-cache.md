# 任务：分场景缓存占用与关闭清理

- 状态：完成
- 用户目标与范围：三个场景各显示实际磁盘占用；关闭有缓存的场景须确认并清理，取消保持开启，无缓存直接关闭；修正清理按钮因设置互斥闪动；字体移到颜色主题后、目录前。
- 不在范围：容量配置、图片编辑、权限或依赖变更。
- 相关规范 / ADR：[缓存版本 ADR](../adr/0014-scoped-thumbnail-cache.md)、[缓存设置](0038-image-cache-and-menus.md)、[数据安全](../data-safety.md)、[设计](../design.md)。

## 验收条件

- 各场景版本独立统计、清理和淘汰；关闭不清理其他场景、正文预览、原图及其他材料。
- 确认 / 取消 / 无缓存 / 偏好失败 / 清理部分失败有明确结果；清理前解码任务不能写回该场景，其他场景仍可缓存。
- 偏好操作不改变清理按钮外观，真实全量清理仍锁定按钮；中英文、小屏和大字体可用。
- 设置顺序为颜色主题、字体、目录、最近、数据管理。
