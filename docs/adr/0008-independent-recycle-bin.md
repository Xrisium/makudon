# ADR 0008：独立回收站与跨索引事务

- 日期：2026-11-02
- 状态：接受并实施；实际验证与限制见任务 0022
- 依据：用户确认设置页入口、保留“删除”称呼、不自动清理、显示项数与磁盘大小、已删除文件夹内单篇恢复，以及原位置失效时确认恢复到根目录。
- 取代范围：ADR 0003 / 0005 的普通删除后立即清理正文语义；其余保存、索引、剪贴板及 ZIP 协议保留。

## 用户行为

所有普通删除入口仍叫“删除”，确认说明名称、原位置、递归范围和“删除后可以从回收站恢复”。文件夹保留树、空目录及子项；顶层项数按删除根计数。回收站独立二级页支持树内浏览、只读源码预览、单项 / 复选恢复和彻底删除、二次确认清空。不自动过期或按容量淘汰；失败保留原稿，不降级为永久删除。

恢复优先有效的原父目录稳定 ID，名称或位置改变不影响识别；原父目录失效时，必须确认将失效项放到根目录，有效项仍回原位置。支持从已删除文件夹中单独恢复文稿或子目录，其余树保留，即使为空也不自动删除。单独先删除的子稿与后来删除的父目录是独立回收站条目。

同名恢复使用“（恢复）”“（恢复 N）”，不覆盖、不合并。正文、类型、创建 / 最近打开 / 正文修改时间和可读上一保存版本保留；恢复不伪造正文修改时间。可安全复用的原 ID 继续复用；原 ID 已被当前库占用或磁盘留有材料时分配新 UUID，避免旧快照或不确定残留被覆盖。无合并和重命名推断。

设置页“数据管理”共用卡片依次显示备份与恢复、回收站；入口显示根条目数和实际文件长度合计，包含索引、临时文件及受控待清理材料，不是文件系统分配块统计。彻底删除仅承诺无法从回收站恢复，不擦除既有 ZIP、整库快照或介质历史。

## 独立存储

回收站位于 `filesDir/trash`，不放在工作区代际目录内。`index.properties` 是有界原子 UTF-8 Properties 索引；每个节点有独立回收站 UUID、原条目元数据、回收站父 ID、原位置文字和删除时间。文稿材料使用 `materials/<uuid>/body` 与可选 `previous`，逐篇有界读取、严格校验并原子写入，不将整库正文装入内存。无新依赖或权限。

正常库仍保留 schema 1，新增可选 `trashOperation` 提交凭据，旧库无需搬正文。回收站最多 20,000 节点、索引 8 MiB；正常库继续受 10,000 节点 / 4 MiB 限制。临时材料和待清理引用同样有界；操作预检两个事务结果均可编码，不能提交正常库后才发现收尾索引超限。

回收站不进入纯目录 ZIP；ZIP 导入、完全覆盖、撤回和清理恢复快照都不切换或清空回收站。完全覆盖保留现场仍由已有整库快照负责，不把整个旧库再重复加入回收站。卸载 / 清数据仍会丢失本地回收站，外部 ZIP 才是独立备份。

## 事务及故障恢复

两份索引在同一 IO Mutex 下操作，临界阶段不可取消。删除经过编辑保存屏障；使用稳定 ID 重新校验及父子去重。协议如下：

1. 删除前先将候选材料 UUID 登记为待清理，再写入并回读校验独立正文与上一版本。任何准备失败都不移除源条目。
2. 回收站原子发布 pending 日志，记录操作 UUID、当前库代际、方向、涉及回收站节点和正常库文稿 ID。
3. 正常库一次发布删除后的整批索引，或完整准备恢复材料后一次发布加入整批条目的索引；同次写入操作 UUID 作为提交凭据。
4. 回收站根据正常库凭据提交 / 撤销 pending：删除已提交则保留回收站节点并登记源材料清理；恢复已提交则移除选中回收站节点并登记其材料清理；未提交删除只清候选材料，未提交恢复保留回收站原件并清未发布的正常库材料。
5. 清理前已持久登记引用；尝试全部受控目标，失败保留引用、实际占用与明确重试入口，不显示已释放空间。清源材料前再次核对所属库索引，绝不删除仍在正常目录中的 ID。

原子替换后回读失败同样视为结果不确定，失效相应可写句柄。此时阻止后续保存及库切换，要求重新载入；先载入库，再按凭据协调回收站，然后更新界面、活动会话与失效选择。不能凭异常猜测是否已提交，也不按残留目录重建文稿。pending 对应代际不符或索引损坏时停止，不能初始化空回收站。

彻底删除先一次移除回收站记录并登记垃圾，再执行材料清理。清理失败后内容已从可恢复列表移除，但待清理提示和空间计数仍存在；可以重试。过去版本的删除残留不自动扫描或承诺找回。

## 验证边界

JVM 测试注入索引替换前 / 后失败，覆盖删除和恢复各发布点、第二篇正文失败、只读预览、树内单篇恢复、同名和原位置、递归清理失败 / 重试、ZIP 隔离与旧库兼容。模拟器和真机结果以任务 / 验收记录为准；逻辑故障注入不等于所有真实断电、硬件故障、强杀时刻或大库性能已经验证。
