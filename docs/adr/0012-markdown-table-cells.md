# ADR 0012：排版表格使用可见单元格输入

- 日期：2026-11-03
- 状态：接受，实施与验证见任务 0028
- 依据：用户要求点击表格直接编辑，删除局部表格源码入口。
- 取代 ADR 0011 中表格点击展开源码与单输入状态的相关约束；普通正文仍共用连续源码输入。

## 决定

私有 Markdown 正文仍是唯一权威内容。排版表格保留源码范围对应的位置，表头和单元格使用原生 Compose 输入镜像，界面显示单元格内容和行内样式。每次输入同步映射回正文，经既有会话 / 修订、容量校验、共享撤销和自动保存发布；没有退出表格时才提交的独立草稿。镜像仅保存输入法组合、选区和输入中的映射，异步解析不替换内容相同的组合态。模式切换、后台和离开沿用同一正文保存屏障。

局部映射保留未编辑单元格、分隔行、对齐标记和表外原文。新输入的 Markdown 标点按字面转义，管道符不产生意外列；边界空格编码为字符实体，避免 Markdown 修剪空格导致逐字输入丢空格。单元格换行转为空格；行列结构调整继续使用源码视图，本轮不加入行列管理工具。空缺单元格首次输入补齐必要分隔符。

背景统一为正文背景，阅读仍只读。删除工具组下方的名称 / 序号。Markdown 单篇只提供 `.md` 原文副本；纯文本保持 `.txt`，ZIP 协议不变。

## 代价与边界

表格局部输入增加原生焦点和输入法镜像协调，需专项验证。普通正文的跨段选择继续使用连续输入框；整体表格源码选择和精确语法编辑使用源码模式。本轮不增加依赖、不迁移存储、不序列化整篇 Markdown。真机输入法人工体验不能以模拟器结果替代。
