# ADR 0016：排版与阅读共用连续正文呈现

- 日期：2026-11-26
- 状态：接受；实施与验证见任务 0050
- 依据：用户要求统一 Markdown 两视图表现，并改善长文切换。
- 取代 ADR 0011 中阅读使用独立块渲染器的约定；不改变正文、保存、撤销及私有库协议。

## 决定

源码、排版、阅读保留同一个连续 `BasicTextField`、原始 `TextFieldState` 和滚动状态。排版与阅读共用源码投影、字体与段落样式、表格几何、图片和任务覆盖层。阅读设置 `readOnly`，且禁止活动源码显露、修改、任务切换和撤销。源码模式保持原文显示。删除独立的 ReadingNode / LazyColumn 呈现路径及第二套滚动锚点。

一致性以无活动编辑标记时的排版为准：同一源码、宽度、字号、行距、主题和位置下，两视图的显示字串、样式范围、换行及基线相同。编辑中的标记显露、组合输入和编辑控件属于必要交互差别。统一后的引用采用正文投影的竖线字形，代码块与正文一起换行，分隔线共用同一表示；不再为阅读额外插入 18dp 块间距和 96dp 页尾。

转义 / 实体按独立 token 映射，避免把整段普通文字替换成一个不可细分的选区。解码复用固定 CommonMark 0.24.0 的 Escaping 工具，由 domain 的解析适配层封装，并以行为测试约束升级兼容性。引用链接、自动链接、Setext 和 ATX 末尾标记、代码空白、有序编号及引用内列表也走同一投影。

阅读选择继续使用原生连续选区；正文复制在明确 Copy 时展开折叠表格，避免复制对象占位符。表格单元格保留独立原生复制动作。阅读查找映射可见文本到源码位置，正文与单元格提供高亮。外链仍只在明确阅读点按时交给已有受限 UriHandler，HTML / 不支持图片保持原文，无网络渲染或权限。

## 长文取舍

采用稳定的原生输出转换器和组件身份，避免排版 / 阅读切换销毁并重建编辑与布局状态；只读状态本身不触发全文替换。空查找查询不扫描全文，正则按投影 / 组件复用，同前缀测量宽度缓存，折叠范围二分定位。行内字体样式应用于可见区、预取区及选区附近，远处显示变换合并。改变换行 / 高度的列表段落缩进及表格高度保留全文几何，避免窗口变化让原生输入框跳回光标。任务及标题按可见源码位置定位，图片、表格覆盖层和表格行仅在视口附近组合。表格共享一个有界 TextMeasurer LRU，并按当前文稿修订、字体 / 密度 / 配色和查找条件缓存几何，源码往返不丢失未变几何。

查阅了 Android 官方 [Lazy 列表](https://developer.android.com/develop/ui/compose/lists)和 [TextMeasurer](https://developer.android.com/reference/kotlin/androidx/compose/ui/text/TextMeasurer)方案。Lazy 布局适合独立条目；将正在编辑的连续正文拆成多个独立输入框，会改变跨段原生选区、IME 和偏移协议。本轮保留连续输入，在实际重型覆盖层、样式与缓存处缩减开销，不引入第二个引擎或升级依赖。

这不是整篇文字的完全虚拟化：原生连续输入仍布局全文，首次从源码进入格式视图仍有明显成本；表格首次几何测量也保留完整高度以稳定滚动范围。性能结论只采用同一模拟器、同一样本的测量，不能代表真机帧率或宣称消除全部长文卡顿。

## 光标与导航

软换行上一行末端使用只存在于输出投影的零宽字符，在原生布局中建立上游光标位置。以 Unicode 码点为单位，既不写入源文，也不拆开代理对。按下时预备显示映射，让原生光标及文本插入手柄共用坐标；手柄拖动期间保留该映射。范围选择 / 复制、输入、组合、失焦、模式切换或下一次正文触摸清理映射。手柄显隐仍由 Foundation 原生策略控制，不另画一个无法拖动的替代指针。

所有视图滚动条仅快速正文手势 / 惯性滚动唤起；约 3 秒无操作隐藏。隐藏时无触摸接收器；可见时只有手柄处理拖动。轨道没有点按定位、进度跳转动作或边缘唤起，也没有回顶 / 回底按钮。显示与隐藏均不参与正文排版。
