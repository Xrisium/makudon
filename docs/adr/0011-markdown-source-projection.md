# ADR 0011：同一源码的连续编辑与三种呈现

- 日期：2026-11-02
- 状态：接受，实施与验收见任务 0026
- 2026-11-03：表格局部源码交互及其单输入状态约束由 [ADR 0012](0012-markdown-table-cells.md) 取代；其他连续编辑约定保留。
- 依据：用户确认源码精准编辑、排版作家式实时预览、阅读只读审阅，并要求重点完善排版工具行为。
- 取代 ADR 0003 中有限段落独立输入框的编辑方案；不改变私有存储、保存或导入副本协议。

## 决定

编辑会话只持有一个 `TextFieldState`。源码与排版复用原生连续文本输入和源码 UTF-16 选区，支持跨段选择；排版的 `OutputTransformation` 只改变显示，显露光标 / 选区 / composition 涉及的标记。阅读使用独立的原生只读 Compose 渲染，无可编辑文本框。Markdown 默认排版，纯文本不出现模式按钮。

CommonMark Java 固定 0.24.0，开启块与行内源码范围，只加表格、删除线、任务列表扩展。依赖已通过现有 Maven Central / Gradle 解析与编译，许可证从实际制品 META-INF/LICENSE.txt 提取并随包展示。不采用 HTML、WebView 或富文本到 Markdown 的全篇序列化。替代方案为继续扩展手写正则解析，但嵌套与转义语义不足，维护成本更高。

解析在 Default dispatcher 的单一互斥队列执行，修订 / 会话与实际源文共同校验后发布。变更结果未到达时，仅将受影响的顶层容器恢复为源码，其余范围按差量平移；不能将旧范围用于命令。解析失败保留文本及源码编辑出口。

长文仅对可见区、预取区及光标端点附近应用字体样式；远离这些范围的连续显示变换合并处理，可见区仍保留精细映射。源码 / 显示偏移使用索引查询。整篇替换时只建立一个受影响的临时源码块，避免按旧段落重复复制大段新正文。

格式命令、任务勾选和查找替换使用明确源码范围。所有编辑先验证 10 万码点 / 1 MiB，再一次发布到原有正文状态。链接等延迟命令记录会话与修订，过期不执行。共享有界撤销记录正文差量及前后选区，显式命令一次撤销，保存与视图切换不进历史。保留原有容量边界，不恢复单篇历史。

排版中的表格在同一文本框内保留源码范围对应的预览位置，点击展开局部源码；不另建可写副本。阅读任务框只读。外链只在明确动作或阅读中交给系统 HTTP / HTTPS / mailto 处理，不添加 INTERNET 权限或资源下载。

## 代价与边界

正文仍为标准 UTF-8 Markdown，不迁移索引格式。显示映射、IME 及复杂结构定位需要专项验证；模拟器组合输入不能代替搜狗等真机候选体验。当前三模式在进程编辑会话中保留，不新增逐稿跨进程模式偏好。具体行为与验证见规范 0005、任务 0026 及当前状态。
