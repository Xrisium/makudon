# ADR 0004：取消自动收件箱，以根目录作为默认位置

- 日期：2026-10-26
- 状态：接受并实施
- 依据：用户要求删除自动创建“收件箱”的特性。
- 关联：补充 ADR 0003 的默认目录行为，不改变私有正文、目录索引格式与单写者协议。

## 决定

新工作区只创建文稿库根目录。从最近新建和系统“打开方式”导入均默认使用根目录，不隐式沿用最近浏览的目录。目录入口仍使用当前选中的有效文件夹，新建页明确展示目标并允许更改；新建页内的导入沿用该页选定位置。

既有 `inbox` ID 的文件夹及全部后代原样保留，不自动删除、移动、改名或改写索引。它成为普通文件夹，可以重命名、复制、剪切、移动和在确认后删除；不再作为默认位置，也不再默认展开。用户创建同名文件夹同样没有特殊行为。

保留 schema 1 对旧 `inbox` 文件夹 ID 的读取及安全校验，仅用于兼容已有数据，不为新目录分配该 ID。没有数据迁移，不需要在更新时写入或清理既有材料。恢复旧版应用读取同一索引的能力不作承诺（旧版仍有收件箱特殊行为）。

## 验证与限制

JVM 回归覆盖新工作区根目录创建和重启、真实 schema 1 夹具读取不改写索引、旧收件箱重命名 / 移动后稳定 ID 与完整正文、阻止目录环，以及删除后重启不重建。设备端的最近新建、系统导入默认位置仍须上手验收。
