# ADR 0006：纯目录 ZIP 与整库代际切换

- 日期：2026-10-27
- 状态：接受并实施；验证见任务 0016 与 ZIP 验收记录
- 依据：用户确认纯目录 ZIP、三种模式及其顺序 / 辅助说明，并授权实现；扩展 ADR 0003 的库级事务边界，不改变库内 schema 1。

## 归档格式与冲突

ZIP 只有实际目录、空目录及 UTF-8 `.md/.txt` 当前正文，无清单、稳定 ID、设置或上一版本；电脑自行创建的同类 ZIP 合法。导出不额外套目录，导入保留源顶层目录。名称无法同时表示的文件 / 目录物理路径在导出前预览副本名，不修改原库。正文保留类型与内容；导入沿用 BOM 去除、CRLF / CR 转 LF 和严格文本限额。

模式固定为单独保存（默认）、增量更新、完全覆盖。增量按相对路径 / 类型及现有名称规则匹配，同文跳过，同目录合并，本地独有内容保留；正文不同逐项确认保留本地 / 采用备份 / 保留双方，界面建议保留双方，未确认冲突不预先占用副本容量。不同路径视为新增，不推断重命名身份，不按时间自动覆盖或自动合并正文。保留双方使用新 ID 和恢复副本名；仅采用备份时保留匹配的本地 ID。

新增项创建时间取恢复时间、opened=0，正文修改时间取合法 ZIP 时间或恢复时间。ZIP 不保留原创建 / 最近打开元数据。普通 ZIP 时间精度及手机时区由 ZIP 约定决定，不当作版本依据。

所有外部来源只读；系统 SAF 创建输出。全包检查 ZIP 结构 / CRC、严格 UTF-8、重复路径、路径穿越、文件占用目录路径及限额。其他类型列明跳过，受支持正文非法则整包拒绝。512 MiB 输入与累计展开、20,000 条目、128 层；在 ZipFile 分配条目表前读取有界尾部，限制 ZIP 中央目录为 16 MiB，拒绝分卷和异常结束记录。恢复后继续受 10,000 节点 / 4 MiB 索引、每篇 10 万码点 / 1 MiB 限制。空正文合法，无正文包不允许恢复。备份恢复可有空文件夹；空文稿库可以导出，但无正文 ZIP 仍不恢复。

## 库级事务

`filesDir/library-state.properties` 原子记录当前库、最近恢复前快照、时间和待清理旧快照 ID。首次读取既有库时建立该小指针，旧 `filesDir/workspace` 正文不搬迁；新库位于 `library-generations/<uuid>`，每个库内部仍使用 schema 1、独立 UUID 正文和原保存协议。

在同一 IO Mutex 下，先经过活动编辑器保存屏障，冻结预览期间的变更，记录包含索引 / 当前正文 / 修改时间的基线指纹。完整准备独立候选库并校验后再次核对基线，一次发布当前库及快照指针。切换前取消或普通失败不发布；临界发布不可取消，结果不确定时失效所有可写句柄，必须重读。已有代际而指针缺失、指针非法或当前索引缺失时停止，不选旧现场、不创建空库。

新旧库不共享可变正文。未改变的文稿保留当前正文及其上一版本，导入 / 替换稿只有当前正文；操作前整个旧库原样成为最近快照，因此原上一版本与恢复现场仍在。旧编辑会话写入同时检查库实例与代际，防止迟到回调写入新库。

撤回交换当前库与最近快照，撤回前现场成为新快照，可再次返回；不自动过期。后续成功恢复替换最近快照，清理旧快照；清理失败保留受控待清理引用，允许手动重试。手动清理先发布移除引用，再清理材料；只删除经验证且不属于当前库 / 最近快照的受控库目录。

准备阶段普通取消 / 失败清理未发布候选，提交不确定时绝不猜测候选是否可删除。进程强杀准备阶段可能留下未引用代际及缓存暂存，不自动重放，也不扫描它们重建当前库；一般孤立材料维护仍在后续范围。库内历史恢复材料沿用原约定，不当作独立备份。卸载 / 清数据仍会删除本地库及本地快照，外部 ZIP 才是独立备份。

## 代价与边界

保持单模块，使用标准 ZIP / Properties / SHA-256，无新增依赖或权限。恢复要同时容纳当前库、已有快照、源暂存和候选库；Android 使用 StorageManager 查询可分配空间，实际 I/O 失败仍必须保留旧库。导出先生成并回读校验私有 ZIP，完整写出及关闭 SAF 流后才报告成功；失败保留私有 ZIP 供重试，外部目标可能存在半成品。

不是跨介质同步协议，不承诺突发断电 / 目录 fsync / 硬件介质故障下零丢失。真实强杀矩阵、多厂商 provider 及长时间大库性能与真机人工验收仍需独立验证。
