# ADR 0014：按场景隔离缩略图版本与清理

- 状态：已接受，已实现
- 日期：2026-11-13
- 补充：[ADR 0013](0013-library-images.md)；取代任务 0038 中跨场景共享同一派生文件及关闭时保留缓存的取舍。

## 决定

目录树、长按菜单、更多信息的缓存键包含场景，场景内继续按内容摘要与尺寸档位复用。统一内存及磁盘 LRU，上限仍为原来的 32 MiB / 堆八分之一和 64 MiB，不为每个场景分别扩大配额。

二级页分别显示三种版本的实际磁盘字节，总占用包括正文 / 图片选择等其他预览。旧版共享键没有场景归属，保留为其他预览缓存；新场景不复用它们，统一清理可以回收，不迁移或读取原图来预生成新版本。

关闭时检查磁盘与内存。存在缓存则确认，取消保持原开关及缓存；无缓存直接关闭。确认先原子写入偏好，成功后才清理对应场景的内存与磁盘；偏好失败不清理缓存，清理部分失败保留关闭状态并显示剩余占用和错误。其他场景、原图和所有权威材料不受影响。

清理使用全局递增序号及各场景清理时间戳。旧请求不能回写已清理的场景，其他场景的请求仍可完成；全量清理继续阻断所有旧写入。占用刷新同样使用请求序号，过期统计不能覆盖清理后的新结果。

## 取舍

独立版本可能增加相同图片的派生字节，但能够准确统计和单独清理，并由原有总容量限制约束。暂不提供独立容量配额、单项删除或原图压缩。按钮视觉状态与操作互斥分开：普通偏好写盘保持清理按钮外观，回调拒绝冲突动作；全量清理仍显示真实忙碌状态。

## 验证依据

JDK 17 Check、183 项单元测试及 API 36 模拟器专项 / 图片回归 119 项通过，详见[验收记录](../testing/2026-11-13-scoped-thumbnail-cache.md)。
