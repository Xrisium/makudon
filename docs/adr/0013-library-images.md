# ADR 0013：私有图片文件与稳定引用

- 状态：已接受，已实现；验收边界见任务 0037
- 日期：2026-11-12

## 决定

图片是目录的一等文件，原始字节私有保存；支持 JPEG、PNG、WebP，每张最多 20 MiB / 100 百万像素。图像元数据携带独立于目录节点 ID 的 UUID 引用标识。Markdown 使用 `makudon-image:<UUID>`，移动 / 重命名不改正文；复制批次内及恢复冲突仅重映射该批次正文。普通回收站恢复保留标识。

ZIP 不携带私有协议清单：导出转普通相对路径，导入先确定图片冲突和映射，再转换文稿。缓存为可丢弃派生材料，不进入库、回收站、快照或 ZIP；清理仅作用于专用缩略图目录。

目录 / 回收站索引版本 2 兼容读取版本 1，首次写入新版前保留旧索引，不迁移 / 重写旧正文。不支持旧版本程序读取含图片的新索引，不承诺降级兼容。

## 取舍

库内源码使用应用 URI，以避免移动图片时跨文稿改写及保存竞争；对外导出保持普通 Markdown 可用。原图不压缩，有界采样和缓存控制预览成本。首版只渲染独立段落图片。

图片引用转换只替换地址，保留行内替代文字格式、标题及空白；引用式图片转换为等价行内形式时保留其标签和标题语义。增量恢复按图片格式区分路径，不能把不同扩展名的图片当作同一目标替换。
