# ADR 0010：移除单篇历史版本与恢复

- 日期：2026-11-02
- 状态：接受并实施
- 依据：用户明确要求移除文稿历史版本、恢复功能及不再需要的代码，并补全文稿 / 文件夹信息。
- 取代：ADR 0003 中的 `previous.txt` 轮换与单篇恢复现场；ADR 0006 / 0008 中随正文传递上一版本的约定。其余事务协议继续有效。

## 决定

每篇只保存当前 `body.txt` / `body.md`。删除上一版本查看、确认恢复、导航页面、错误分类及关联资源；保存不再写 `previous.txt`，不再创建单篇 `recovery` 现场。ZIP 候选代际与回收站恢复只传递当前正文。

保存调度仍为停顿 500ms / 最长 2s，保留单写者、会话版本及库代际校验、离开屏障、失败后显式重试和内存导出出口。正文继续临时写入、sync、回读、原子替换、完整回读；损坏正文不被空稿覆盖。单篇文件自身已损坏时，没有本地上一版本恢复入口。

编辑撤销 / 重做、删除后回收站恢复、ZIP 整库恢复及最近一次整库快照交换均保留。旧版已落盘的 previous / recovery 材料不扫描销毁，也不再读取或复制；旧文稿目录与整库材料仍沿用现有删除 / 清理生命周期。此决定不引入数据迁移或不明确的孤立材料扫描。

## 条目信息

文稿 / 文件夹的信息入口统一先经过活动编辑器保存屏障并在 IO Mutex 下刷新。时间以手机当前时区、固定数字格式 `yyyy/MM/dd HH:mm:ss` 显示，不随应用语言或系统 12 小时制改成其他格式；时区变化沿用现有系统广播刷新。

创建时间取索引的 `created`；文稿修改时间取当前正文文件 mtime，文件夹取自身与全部后代的最新创建 / 正文修改时间。这是内容及后代时间汇总，不新增重命名 / 移动 / 删除的独立目录时间日志。

逻辑文件夹没有实体目录，磁盘大小为该子树可达文稿私有目录内全部普通文件的字节总和，含暂存与旧材料；空目录为 0 B。统计用 Long，在 IO dispatcher 运行，读取失败明确报告，不静默降为 0；不跟随符号链接。不把共用索引、库级恢复现场、回收站、快照、分享缓存或文件系统块开销分摊到文件夹。

## 代价与验证

不增加依赖或权限。每次信息打开重新统计，避免缓存导致修改 / 移动后的大小失真；大库统计耗时尚未测量。信息弹窗正文可滚动，保留中英双语和字体缩放。
