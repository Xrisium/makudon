# 设备选择与调试约定

- 生效日期：2026-10-24。
- 来源：用户明确要求“有真机连接时仅做真机调试，无真机时做模拟器调试，除非用户主动要求”。
- 适用范围：Agent 的安装、启动、运行验收、截图、Logcat 和 instrumentation / UI 测试。普通编译、JVM 单测与静态检查不需要设备。

## 选择顺序

每次设备操作前重新执行 `Devices` / `adb devices -l`，不要把上次会话的设备序列号当作当前连接事实。

| 当前状态 | 默认行为 |
| --- | --- |
| 一台已授权且在线的真机 | 仅使用这台真机；向 Run / Screenshot / Logcat 显式传入其 `-Serial` |
| 多台在线真机 | 让用户选目标，或遵循用户已明确指定的目标；不随便取列表第一台 |
| 真机与模拟器同时在线 | 仅使用真机；不为补测另行使用模拟器，也不擅自关闭用户已开的模拟器 |
| 可识别真机处于 unauthorized / offline | 先处理手机授权、连接或 ADB 状态；不将“真机暂不可用”解释为“没有真机”并自动启用模拟器 |
| 确认没有真机连接 | 使用已有配置 AVD；优先复用，不额外创建 / 下载镜像 |
| 真机在调试过程中断开或安装 / 运行失败 | 保留结果并处理当前目标问题，不自动切换模拟器重试 |
| 用户本次明确要求模拟器或特定设备 | 按该要求执行；只覆盖本次指定范围，不改变长期默认 |

典型 Android SDK 模拟器序列号为 `emulator-*`；需要时结合设备属性判断其他仿真环境，不把任意非该前缀设备盲目视为真机。设备全量序列号仅用于本次命令或被忽略的本地记录，不写进共享文档。

## 安装频率与用户使用

2026-10-25 用户明确禁止在真机上频繁、反复覆盖安装。该约束同时适用于应用 APK 和测试 APK，包括通过 `Run`、`adb install -r`、Gradle 安装任务及测试工具触发的安装。

- 先集中完成本地代码与测试修改、编译、`Check` 和差异审查，不得每调整一点代码或测试就重新安装。
- 必要的最终设备验收应合并安排；已有安装可复用时直接复用，不为重复同一项检查再次覆盖安装。
- 额外安装须先说明必要原因、安装对象及对当前使用的影响，并获得用户明确授权；不能把例行验收或完成标准当作反复安装的授权。
- 安装前仍须提醒保存，使用保留数据覆盖安装；不得卸载、清数据或重置文稿。
- 用户叫停后，本轮不再安装，包括测试 APK；不得自动切换模拟器绕过。可继续本地编译与静态检查，将设备验收明确记为未完成，后续安装等待用户明确授权。

用户随后明确补充开发验证方式：先集中完成本地构建、测试与检查；需要频繁测试时使用模拟器代替，完成后再向真机合并覆盖安装一次。该明确授权允许本次在真机在线时使用模拟器进行自动化回归。真机主要交给用户本人上手验收，Agent 不再以反复 ADB 调试和测试包安装作为默认验收方式。最终真机安装前仍重新识别目标、提醒保存并保留数据。

## 当前脚本能力与使用方式

**`android.ps1`、`test-android.cmd` 和 VS Code 任务尚未实现自动“真机优先”分流。** 无 `-Serial` 的现有 Run / Logcat / Screenshot 会选配置 AVD；无参数双击和 `Ctrl+Shift+B` 仍调用这个路径。有真机时，Agent 不得使用这些默认路径，必须先识别真机并传参：

```powershell
pwsh -NoProfile -File scripts/android.ps1 -Action Devices
# 把 YOUR_SERIAL 替换为本次识别到的目标真机序列号
pwsh -NoProfile -File scripts/android.ps1 -Action Run -Serial YOUR_SERIAL
pwsh -NoProfile -File scripts/android.ps1 -Action Screenshot -Serial YOUR_SERIAL
pwsh -NoProfile -File scripts/android.ps1 -Action Logcat -Serial YOUR_SERIAL
# 批处理也已支持参数转发
.\test-android.cmd -Serial YOUR_SERIAL
```

VS Code 可运行任务 `Makudon: Run on selected device`，填入当前真机序列号。只有无真机或用户明确选择模拟器时，才使用无参数入口及 `Makudon: Start emulator`。

后续若获准修改工具脚本，应把上表落实到所有设备命令及快捷入口，并测试授权失败、多设备、运行中断连与显式覆盖；在此之前由 Agent 按本约定选择设备，不能声称脚本已经自动切换。
