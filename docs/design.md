# 视觉与交互原则

更新：2026-11-14。用户已采用方案并要求直接制作应用，当前已接入原生工作区；以下保留视觉依据与待讨论参数，实际实现 / 验收以 [当前状态](status.md) 为准。

## 用户明确的方向

- 简约、现代、Soft Minimalism，以黑白为主，柔和圆角，优先编辑与阅读舒适度和平滑动画。
- 多套可切换颜色主题，包含深色；保持干净、柔和、低饱和。日系的温暖轻松感通过留白与比例表达，不使用猫爪、樱花等装饰符号。
- 界面使用 Noto Sans 系列 Medium（500）；用户本轮要求正文试用 450，不可用时回退 400。两个字体角色分开，未来允许分别选择系统字体或自选字体文件，本轮只记录边界，不实现正式切换或空接口。
- Fredoka Semibold（600）只用于生成 Makudon 路径字标，与现有图标配合；不在应用内嵌入 Fredoka 字体。
- UI 操作图标采用 Lucide；用户指定 Markdown 文件类型标识使用 Fluent Markdown 20 Filled，属于类型标识例外。素材管理遵循[第三方素材规范](third-party-assets.md)。

设置布局与文案遵守下列长期规则。原同类设置归并原则于 2026-11-12 确认，2026-11-14 进一步明确分类 / 卡片范式及提示文案约束。

## 界面文案：必要、简短、就地

- 尽量少向用户展示功能原理解释性、安慰性、重复性的提示文本；默认不添加此类常驻说明。仅保留必须存在的特定说明，例如删除 / 覆盖 / 清理的二次确认、当前操作的真实风险和范围、会影响选择的限制、保存失败与恢复动作。
- 控件名称、当前值、操作结果和必要状态本身能表达的信息，不再用额外段落重述。没有当前决策需要或用户明确要求时，不展示后台流程、缓存生成 / 复用机制、实现架构或与当前操作无关的数据保留保证。技术详解放开发文档或按需帮助。
- 必要说明放在发生相关选择、风险或失败的地方，不把确认框内容复制成页面常驻提示。错误提示应说明实际问题及可执行的下一步，不能为了精简隐藏未保存、可能覆盖、不可恢复或部分失败。
- 新增文案前先检查是否已有标签、状态、确认或错误覆盖同一信息；没有独立作用的句子不新增。避免先增加解释或安抚段落，再等待用户反复要求删除。
- 审查现有文案时先核实实际展示位置，列出原文及判断；用户要求先确认的候选不得擅自删除或改写。中英文含义与显示范围保持一致。
- 用户明确确认必要的特定文案优先于通用删减判断。2026-11-14 已确认保留：缓存清理说明、目录操作提示、回收站只读提示、ZIP 格式 / 来源 / 跳过边界、库切换与恢复 / 撤回结果中的操作说明（[C1–C6](reviews/2026-11-14-ui-copy-and-settings-layout.md)）。后续不得仅因这些说明具有解释性就再次机械建议删除；格式范围随实际支持能力同步更新。

## 设置界面：分类标题与分组卡片

- 主设置页及设置类二级管理页采用连续的“卡片外分类标题 → 对应卡片内容 → 下一分类标题 → 对应卡片内容”层次。分类标题统一使用次级文字颜色与 `bodySmall`，不得把分类标题嵌进卡片后再用说明段落填补外部标题位置。
- 同一分类中的相关设置 / 管理条目共用一张卡片；不同设置项、控件组或操作组之间用左右内缩分隔线区分，不拆成多个独立圆角块，不为每一行再套卡片。
- 同一条目的名称、当前值、占用、必要状态属于一个内容组，组内换行不另加分隔线。卡片内可保留字段标签 / 单选组标签，例如“图片显示方式”“排列依据”“缓存总占用”；这些不是卡片外的分类标题。
- 单个设置的可视候选可以使用主题色块、字体预览选项或分段控件，其选项不算多个独立设置项。预览样本、文稿 / 文件清单、版权正文、操作确认与错误反馈不强行套用设置卡片范式。
- 同页同级标题、分类间距、卡片圆角、条目内边距与分隔线内缩保持一致，沿用当前主题。单独快捷入口或页脚链接若保留为例外，须有明确用途，不能借例外规避普通设置条目的分组。
- 示例：“最近”分类卡片中，概览开关与排列依据使用分隔线；“缓存概览”标题在卡片外，卡片内显示缓存总占用，并以分隔线区分概览信息与全量清理操作。

## 布局与层次建议（待讨论）
- 编辑区保留完整留白，不把正文放进浮起的卡片。圆角主要用于按钮、菜单、设置面板和必要的列表容器。
- 首片以最小文稿列表和单活动编辑器为主，不因例图增加目录树、搜索、Markdown 工具栏或预览。外观设置画面属于后续设计。
- 用户已选择“柔和卡片”：用柔和底色区分稿件，不叠加重阴影。主界面为“目录 / 最近 / 设置”，默认最近；最近页右上角单个 Lucide `plus` 按钮进入三选项新建二级页，保留“新建文稿”无障碍名称，取代“本机”，不再显示新建卡片。最近页无原标题口号，不显示扩展名。见[导航与双视图设计](specs/0003-workspace-and-markdown-views.md)。
- 目录删除新建位置 / 新建操作卡片和行尾“…”；“选择文件夹可更改新建位置，长按显示更多”作为搜索框下方单行纯文本提示，无图标、底色或当前路径。工具顺序为搜索、排序、展开 / 收起、创建目录、新建文稿。窄屏让工具按钮换到标题下方一行，热区保持 48dp，不压缩按钮。
- 目录新建文稿图标为 Lucide `file-plus-corner`。长按菜单进入行尾复选，普通目录外观保留；模式内顶部仅 X / 数量 / 清空选择，下接目录树，底部为复制 / 剪切 / 粘贴 / 删除，不保留搜索或其他占位区域。清空不退出，界面退出统一由 X 控制；多目标粘贴须明确选定一个位置，详见 [复选规则](tasks/0013-directory-multiselect-preview.md)。
- 长按文件 / 文件夹显示同主题圆角菜单，提供信息、重命名、复制、剪切、粘贴、删除；仅文件夹提供新建文件夹 / 文稿。重命名保留文件类型，删除置于菜单末尾并使用柔和警示色；删除确认框显示名称、位置和目录子项范围，默认焦点为取消。桌面例图提供右键和键盘替代操作，Android 可访问性动作待正式实现。
- 排序采用主题化圆角浮层，以图标、名称、勾选和升降序分段明确状态；各排序依据与方向有相应按钮图标。展开 / 收起的整体动作及逐项箭头均有差分，同时同步无障碍动作名称。
- 文件夹整行短按同时选中并展开 / 收起，箭头仍可独立展开 / 收起。目录操作通知位于提示文字下方，保留原有样式。源码 / 排版按钮按压与选中背景统一使用 11dp 圆角。
- 正文建议从 18sp、1.85 倍行高、两侧 24dp 起试，标题层次以字号和间距为主；这些是视觉起点，未经真机验证。
- 控件圆角从 16–20dp 起试；底部弹层可更圆。操作热区至少 48dp，不随视觉图标尺寸缩小。
- 正常编辑全自动保存，无常规手动保存按钮；按 2026-11-12 用户要求，不显示常规保存状态文字。保存失败同时显示文字、可辨提示色和重试 / 导出出口，不能仅靠图标、颜色或短暂 Toast。

## 图片缓存与阅览菜单

- 设置中的缩略图缓存打开与回收站 / 备份同级的二级页面；标题和返回固定，场景开关、占用、清理操作整体可滚动。目录树、长按菜单、更多信息的缓存开关同卡片归并，每行显示对应版本的磁盘占用，默认开启；关闭有缓存的场景须确认，取消不改变开关，无缓存直接关闭。全量清理同样需要再次确认；取消不更改任何缓存或偏好，确认面板说明清理范围。普通偏好写盘保持清理按钮外观，并在动作回调拒绝冲突操作。
- 图片阅览菜单沿用文稿编辑的 18dp 圆角、260–300dp 宽度及图标样式，顺序为详细信息、重命名、导出、分隔线、删除。回收站只提供详细信息和导出，恢复与彻底删除沿用回收站入口。重命名保留当前缩放和位移；删除复用引用影响确认，成功后关闭该图片。
- 文稿编辑菜单先显示正文大小与行距分段控件，再显示查找与替换，随后分隔线及文件操作。新建页“导入文稿”卡片保留原图标，不再显示下方导入说明框。简中图片尺寸单位为“像素”。

## 字体角色与覆盖

- 使用 `UiFont` 与 `EditorFont` 两个语义角色，初始可共享同一字体文件，不能把编辑正文直接绑定成界面字体的别名。未来切换其中一个不改变另一个。
- 简体中文例图使用 Noto Sans SC，它包含本例所需中西文；正式字体覆盖、其他 CJK 地区字形和 emoji 回退需要单独确定。允许缺字和 emoji 回退，不能为避免系统字体而把字符显示为空框或替换正文。
- 正文当前试用 450，界面保持 500；保留正文 400 / 500 比较。Noto Sans SC 的可变 `wght` 轴覆盖 100–900，可真实插值 450。长时间中文输入 / 阅读的舒适度仍需由用户真机判断。
- 源 Noto Sans SC 可变字体本次下载为 17,772,300 字节（约 16.95 MiB）；不是未来 APK 增量。正式方案须实测单字重、完整覆盖范围和包体，不预装多地区全套字体，也不能仅按例文裁剪正式字体。
- 本次例图使用只覆盖例图文字、400–500 范围的设计专用子集；该子集不得用于正式编辑器。
- 本轮只预留设计与职责边界，不新增字体仓库、设置存储或导入文件框架。自选字体解析失败的回退、导入授权和许可提示在实现时设计。

## 品牌与图标

- 根 `icon.svg` 是用户提供的原始资产：开放 M + 分离竖笔 + 向下箭头。未经要求不重画；Android 矢量复用原始路径，自适应图标保留安全边距。
- [字标与组合草案](../assets/brand/README.md)由真实 Fredoka 600 / 宽度 100 生成轮廓，保留 kerning 并增加极小字距；尚待视觉确认。SVG 无文本节点和字体依赖。
- 组合标志只调整原图标的比例、位置、颜色继承及透明背景；原始路径几何与根 `icon.svg` 不变。
- 品牌组合适合文稿入口、关于页和必要的启动展示；编辑页让位给文稿，不常驻大 Logo，不为展示商标额外延长启动动画。
- Lucide 从 24×24 画布、约 1.8–2 的线宽起试，统一圆端点；按需导入实际使用的图标，不引入整套图标字体或未经评估的 Compose 封装。操作图标不混用其他风格。

## 动效与验收

- 主标签采用离散导航事件：点击底栏或明确横向滑动松手后，统一播放 240ms / FastOutSlowIn 的横向过渡，页面位置不跟随手指。横向位移须达到 48dp（且至少为两倍系统 touch slop），并至少为纵向位移的 1.5 倍；屏幕左右 24dp 留给系统边缘手势。长按、轻微抖动、取消、纵向滚动及子控件已接管的手势不切页。
- 标签顺序仍为“目录 / 最近 / 设置”，首尾不循环。跨标签只在起点和终点之间移动一屏，跳过中间页面，位移和时长与相邻切换一致；过渡期间忽略重复导航，不排队。底栏使用单个实色选中背景，与页面共享 240ms / FastOutSlowIn 横移进度，跨标签直接移动至目标；图标和标签文字同步平滑变色。背景经过中间标签不代表打开中间页面；底栏与主页面一起进退，不单独挤压正文。
- 页面过渡通过独立输入门控阻止重复操作，不以控件 disabled 表示滑动或过渡，避免主题选项、许可文字和目录控件突然置灰。保留真实业务忙碌时的禁用状态与 Material 默认按压反馈。
- 二级页面向右侧 24dp 淡入 220ms，返回反向退场 200ms；新建 / 导入成功进入编辑页，文稿返回来源主页面。退出先冻结输入并通过最新输入保存屏障，保留退场会话直到最后一帧，失败则继续编辑。
- 主题各颜色角色按统一进度渐变 240ms，连续切换从当前颜色继续；首次加载、相同有效配色与渐变端点使用精确颜色。重复选择当前配色不写盘、不启动忙碌状态；配色持久化仍互斥并显示失败，但不短暂置灰设置控件 / 底栏或闪现进度条。系统栏图标跟随背景明暗切换，不对整页文字做交叉淡化。
- 搜索框高度 / 透明度和列表增删 / 移动 / 排序 180ms，目录箭头旋转与源码 / 排版选中背景 160ms。搜索输入期间禁用列表动画；首次加载和返回列表不逐项入场。正文视图直接切换，错误提示只淡入，不动画改变编辑区高度。
- 默认 `FastOutSlowIn` 位移缓动；按压、菜单和弹窗复用 Material 反馈。不做持续呼吸、循环装饰、共享元素或夸张弹跳；不额外增加动效设置。
- 减少动态效果时去除非必要位移与缩放。正文、光标和输入法组合态不得随保存状态刷新跳动；不对每次输入播放动画。
- 遵循系统动画倍率；倍率为 0、Activity 重建或进入后台时也须完成会话清理且不遗留输入锁。实际覆盖与限制见[动效验收](testing/2026-10-25-motion.md)。
- 支持 TalkBack、系统字体缩放、横屏、系统栏及输入法避让。正式图标可触性、文字裁切和主题系统需要 Android 实现后验证。
- 必须真机检验中文输入组合、长文滚动与持续阅读；浏览器例图和模拟器截图都不能替代。

全局行距沿用字号控件；纯文本双视图与有条件显示的左右长文导航见[规范 0006](specs/0006-reading-and-navigation.md)。
