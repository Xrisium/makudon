# 视觉与交互原则

更新：2026-10-25。以下区分用户明确方向与待讨论参数；本轮是设计讨论，未修改 Android 界面实现。

## 用户明确的方向

- 简约、现代、Soft Minimalism，以黑白为主，柔和圆角，优先编辑与阅读舒适度和平滑动画。
- 多套可切换颜色主题，包含深色；保持干净、柔和、低饱和。日系的温暖轻松感通过留白与比例表达，不使用猫爪、樱花等装饰符号。
- 界面使用 Noto Sans 系列 Medium（500）；用户本轮要求正文试用 450，不可用时回退 400。两个字体角色分开，未来允许分别选择系统字体或自选字体文件，本轮只记录边界，不实现正式切换或空接口。
- Fredoka Semibold（600）只用于生成 Makudon 路径字标，与现有图标配合；不在应用内嵌入 Fredoka 字体。
- UI 操作图标采用 Lucide；用户指定 Markdown 文件类型标识使用 Fluent Markdown 20 Filled，属于类型标识例外。素材管理遵循[第三方素材规范](third-party-assets.md)。

## 布局与层次建议（待讨论）

- 编辑区保留完整留白，不把正文放进浮起的卡片。圆角主要用于按钮、菜单、设置面板和必要的列表容器。
- 首片以最小文稿列表和单活动编辑器为主，不因例图增加目录树、搜索、Markdown 工具栏或预览。外观设置画面属于后续设计。
- 用户已选择“柔和卡片”：用柔和底色区分稿件，不叠加重阴影。主界面为“目录 / 最近 / 设置”，默认最近；最近页右上角“新建文稿”图标文字按钮进入三选项新建二级页，取代“本机”，不再显示新建卡片。最近页无原标题口号，不显示扩展名。见[导航与双视图设计](specs/0003-workspace-and-markdown-views.md)。
- 目录删除新建位置卡片，提示放在工具栏下方并显示当前目标；工具顺序为搜索、排序、展开 / 收起、创建目录、新建文稿。窄屏让工具按钮换到标题下方一行，热区保持 48dp，不压缩按钮。
- 排序采用主题化圆角浮层，以图标、名称、勾选和升降序分段明确状态；各排序依据与方向有相应按钮图标。展开 / 收起的整体动作及逐项箭头均有差分，同时同步无障碍动作名称。
- 正文建议从 18sp、1.85 倍行高、两侧 24dp 起试，标题层次以字号和间距为主；这些是视觉起点，未经真机验证。
- 控件圆角从 16–20dp 起试；底部弹层可更圆。操作热区至少 48dp，不随视觉图标尺寸缩小。
- 正常编辑全自动保存，无常规手动保存按钮；状态持续可见。保存失败同时显示文字、可辨提示色和重试 / 导出出口，不能仅靠图标、颜色或短暂 Toast。

## 字体角色与覆盖

- 使用 `UiFont` 与 `EditorFont` 两个语义角色，初始可共享同一字体文件，不能把编辑正文直接绑定成界面字体的别名。未来切换其中一个不改变另一个。
- 简体中文例图使用 Noto Sans SC，它包含本例所需中西文；正式字体覆盖、其他 CJK 地区字形和 emoji 回退需要单独确定。允许缺字和 emoji 回退，不能为避免系统字体而把字符显示为空框或替换正文。
- 正文当前试用 450，界面保持 500；保留正文 400 / 500 比较。Noto Sans SC 的可变 `wght` 轴覆盖 100–900，可真实插值 450。长时间中文输入 / 阅读的舒适度仍需由用户真机判断。
- 源 Noto Sans SC 可变字体本次下载为 17,772,300 字节（约 16.95 MiB）；不是未来 APK 增量。正式方案须实测单字重、完整覆盖范围和包体，不预装多地区全套字体，也不能仅按例文裁剪正式字体。
- 本次例图使用只覆盖例图文字、400–500 范围的设计专用子集；该子集不得用于正式编辑器。
- 本轮只预留设计与职责边界，不新增字体仓库、设置存储或导入文件框架。自选字体解析失败的回退、导入授权和许可提示在实现时设计。

## 品牌与图标

- 根 `icon.svg` 是用户提供的原始资产：开放 M + 分离竖笔 + 向下箭头。未经要求不重画；Android 矢量复用原始路径，自适应图标保留安全边距。
- [字标与组合草案](../assets/brand/README.md)由真实 Fredoka 600 / 宽度 100 生成轮廓，保留 kerning 并增加极小字距；尚待视觉确认。SVG 无文本节点和字体依赖。
- 组合标志只调整原图标的比例、位置、颜色继承及透明背景；原始路径几何与根 `icon.svg` 不变。
- 品牌组合适合文稿入口、关于页和必要的启动展示；编辑页让位给文稿，不常驻大 Logo，不为展示商标额外延长启动动画。
- Lucide 从 24×24 画布、约 1.8–2 的线宽起试，统一圆端点；按需导入实际使用的图标，不引入整套图标字体或未经评估的 Compose 封装。操作图标不混用其他风格。

## 动效与验收

- 建议按压反馈约 120–160ms，页面 / 面板过渡约 180–240ms，以短距离位移和自然缓动为主；不做持续呼吸、循环装饰和夸张弹跳。具体参数待性能验证。
- 减少动态效果时去除非必要位移与缩放。正文、光标和输入法组合态不得随保存状态刷新跳动；不对每次输入播放动画。
- 支持 TalkBack、系统字体缩放、横屏、系统栏及输入法避让。正式图标可触性、文字裁切和主题系统需要 Android 实现后验证。
- 必须真机检验中文输入组合、长文滚动与持续阅读；浏览器例图和模拟器截图都不能替代。
