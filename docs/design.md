# 视觉与交互原则

- 白底深色线条，简约现代，圆润、温暖、轻松；不要把它做成专业 IDE 或极客控制台。
- 日系感通过留白、比例、柔和圆角和节奏表达，不使用明确猫爪、樱花等装饰符号。
- `icon.svg` 是用户提供的原始资产：开放 M + 分离竖笔 + 向下箭头。未经要求不重画。
- Android 矢量资源复用原始路径；自适应图标增加安全边距，避免系统圆形蒙版裁切箭头。
- 默认尊重系统浅色/深色模式，不为“品牌纯白”牺牲夜间阅读；实际阅读主题在后续功能中设计。
- 文字内容优先于工具栏；常用编辑动作易触达，非必要操作收敛，空状态不堆按钮。
- 交互控件至少 48dp 可触区域，支持 TalkBack、字体缩放、横屏、手势导航和输入法遮挡处理。
- 未来必须真机检验中文输入组合与长文滚动；模拟器截图不能替代编辑舒适度评价。
