# 代码规范

- Kotlin 官方风格，4 空格，UTF-8；类型/Composable 使用 PascalCase，普通函数/变量使用 camelCase，包小写。
- 优先 `val`、不可变状态、清晰的小函数；注释解释约束和原因，不翻译显然的代码。
- UI 文案用资源字符串，未来需要本地化时以中文体验验收；品牌名不翻译。
- Composable 尽量无副作用、可预览数据可替换；公开 UI 接受 `Modifier`，状态从上层传入。
- 副作用放生命周期感知作用域；耗时 I/O 放 IO dispatcher，取消不能被通用异常捕获吞掉。
- 不用 `!!` 掩盖未知状态，不空 catch，不把失败当空列表或保存成功。
- 不为每一类造接口；在测试替身或存储边界需要时再抽象。
- 依赖统一在版本目录，固定版本；AGP 9 使用内置 Kotlin 与同版本 Compose compiler。
- Android Lint 的错误和警告都阻止 `Check`。如需抑制，局部抑制并说明原因，不整体关掉检查或创建一份吞掉全部问题的 baseline。
- 编辑器格式化依赖现有 JetBrains 扩展；当前没有引入 ktlint/detekt，避免为基础工程重复安装工具。`.editorconfig` 作为格式约定。
- 测试针对行为、恢复与失败路径；初始静态空壳不创建伪装业务覆盖率的示例测试。
